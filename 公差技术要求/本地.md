# 本地工作目录（已锁定）

**工作目录：** `C:\ABC\My Work\DA Std`

仓库里已放工作区文件 **`DA Std.code-workspace`**。在 Cursor 里：

**File → Open Workspace from File…** → 选仓库中的 `DA Std.code-workspace`

或 **File → Open Folder** → 直接选 `C:\ABC\My Work\DA Std`。

打开后左边根目录就是 `DA Std`。公差 MD：

`C:\ABC\My Work\DA Std\公差技术要求\`

本地 Agent，不要 Cloud。聊天不作准。

## 若该目录里还没有 MD

**情况 A：** `C:\ABC\My Work\DA Std` 就是 git 仓库 `noko119`

```powershell
cd "C:\ABC\My Work\DA Std"
git fetch origin
git checkout cursor/gongcha-jishu-yaoqiu-ce8f
git pull origin cursor/gongcha-jishu-yaoqiu-ce8f
```

然后打开 `DA Std.code-workspace`。

**情况 B：** 工作目录和 git 仓库不是同一个文件夹

在已经 pull 过本分支的仓库根目录执行（路径有空格，引号要留）：

```powershell
New-Item -ItemType Directory -Force -Path "C:\ABC\My Work\DA Std\公差技术要求" | Out-Null
Copy-Item -Force "公差技术要求\*" "C:\ABC\My Work\DA Std\公差技术要求\"
New-Item -ItemType Directory -Force -Path "C:\ABC\My Work\DA Std\.cursor\agents" | Out-Null
Copy-Item -Force ".cursor\agents\gdt-*.md" "C:\ABC\My Work\DA Std\.cursor\agents\"
New-Item -ItemType Directory -Force -Path "C:\ABC\My Work\DA Std\.cursor\rules" | Out-Null
Copy-Item -Force ".cursor\rules\gdt-workdir.mdc" "C:\ABC\My Work\DA Std\.cursor\rules\"
Copy-Item -Force "DA Std.code-workspace" "C:\ABC\My Work\DA Std\"
```

云端不能替你点 Open Folder，也不能写入 C 盘。本地打开一次即可。
