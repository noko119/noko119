# 本地继续（不要云）

云上这条对话**搬不走聊天记录**。之后在你电脑上的 Cursor 本地 Agent 接着做，MD 在仓库里随时改。

## 打开

在仓库根目录：

```bash
git fetch origin
git checkout cursor/gongcha-jishu-yaoqiu-ce8f
git pull origin cursor/gongcha-jishu-yaoqiu-ce8f
```

Cursor：**File → Open Folder** 打开本仓库。左边就能看到 `公差技术要求/`。

对话用**本地 Agent**（Composer / Agent，不要再开 Cloud Agent）。新开一个本地对话即可，标题仍用「公差技术要求」。把 `.cursor/agents/gdt-design-engineer.md` 和 `gdt-process-engineer.md` 当两岗。

云端这条：https://cursor.com/agents/bc-c2d48bf5-3661-41fd-a59c-a06dba70ce8f — 本地接上之后可以不用。

## 如何指定目录

你指定哪个文件夹，以后 MD 就写到哪。两种用法，按你要的选。

### 1. 指定 Cursor 打开哪个文件夹（工作区）

Cursor 菜单：**File → Open Folder**（打开文件夹），选你的目录。  
左边文件树根就是你指定的目录，本地 Agent 默认改这里面的文件。

- 只做公差：打开 `…/noko119/公差技术要求`
- 整仓库：打开 `…/noko119`
- Obsidian 图纸库：打开 `…/图纸库`（不要打开仓库根）

### 2. 指定 MD 放到哪（跟本地 Agent 说一声）

在本地对话里直接发路径，例如：

```
以后公差 MD 都写到：D:\图纸\超轻托辊\公差技术要求
```

或：

```
MD 放到仓库里的 公差技术要求/ ，不要改别的目录
```

说一次即可。之后每次标公差都改你点名的那三份：`现行标注.md`、`缺尺寸清单.md`、需要时 `工作口径.md`。

**目录在仓库里面：** Git 能跟踪，改完 commit。  
**目录在仓库外面：** 文件能改，但 `git push` 带不走；要进 Git 就把该文件夹放进仓库，或自己复制一份进来。

现在默认目录仍是仓库里的 `公差技术要求/`。你把完整路径发来，就改成你的。
