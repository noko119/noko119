## 3. 路径与布置特征（从图读取）

### 3.1 总体侧型
- 长距离上运斜坡主输送
- 头部卸料（约点14附近）
- 尾部受料（约点12/13附近）
- 中部设复杂改向 + 重锤拉紧系统（点1～9、18～22一带）

### 3.2 特性点
- 图中可见编号点约 **1～22**
- 属多滚筒、多改向、重锤拉紧布置
- 适合验证：
  - 高级路径录入（非简单 Auto Return）
  - 拉紧站几何
  - 多点逐点张力编号

### 3.3 对咱们架构的映射

| 咱们模块 | 本案例对应 |
|----------|------------|
| 网页路径录入 | 需支持复杂中部拉紧回路 |
| SW骨架 | 可先录主坡段 + 头尾 + 拉紧回路 |
| DTⅡ分段 | 承载倾斜主段 + 滚筒段 + 拉紧滚筒段 + 受料/卸料 |

| 计算 | 满载上运 + 拉紧边界 |
