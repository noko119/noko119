## 4. 标准计算链（对照答案）

> 公式编号来自 **DTⅡ(A) 设计手册** 用户提供页（约第42页相关章节）。

### 4.1 主要阻力 FH（式3-19）

\[
F_H = f L g [q_{RO}+q_{RU}+(2q_B+q_G)\cos\delta]
\]

| 项 | 值 |
|----|----|
| f | 0.023（多尘潮湿，表3-6） |
| qRO | 29.1 kg/m |
| qRU | 10 kg/m |
| qG | 236.1 kg/m |
| qB | 47.6 kg/m |
| L | 310 m |
| **FH** | **≈ 25525 N** |

### 4.2 特种主要阻力 FS1（式3-24 / 3-25 / 3-27 等）

- \(F_{S1}=F_\varepsilon+F_{gl}\)
- 含前倾等特种主要阻力项（μ0、Lε、ε、δ、qB、qG 等）
- **FS1 ≈ 6100 N**

### 4.3 附加特种阻力 FS2（式3-28 / 3-29）

- 清扫器等附加特种阻力
- n3=5（2个清扫器 + 2个空段清扫器；其中一个空段清扫器按1.5计）
- 查表3-11（A、p、μ3）
- **FS2 = 4200 N**

### 4.4 倾斜提升阻力 FSt（式3-31）

\[
F_{St}=q_G g H=236.1\times9.81\times57.051
\]

- **FSt = 132138.2 N**

### 4.5 圆周驱动力 FU（式3-17）

\[
F_U=C F_H+F_{S1}+F_{S2}+F_{St}
\]

| 项 | 值 |
|----|----|

## 5. 逐点张力（表3-26要点）

### 5.1 起算与方法

- 按不打滑条件，传动滚筒奔离点最小张力取 **S1 = 24946 N**
- 沿运行方向逐点累加（点号约 S1～S22）
- 表列四种计算列：
  1. 按不打滑条件计算
  2. **1:1 双传动**
  3. **2:1 双传动**
  4. **1:2 双传动**

### 5.2 关键规则（已从原文确认）

- 若干相邻点张力相等或按系数传递，例如：`S1=S2`，`S3=S4=1.03×S2` 等
- 回程/局部段含：`f Li g (qRU+qB)`、清扫器阻力 `1.5 Fr` 等
- **2:1 双传动**时：若 `S13 < F承min`，则强制 `S13 = 41746 N`

### 5.3 双驱功率分配与滚筒合力（原文算例）

包角摩擦项取 \(e^{\mu\phi}=3.4\)（原文简化）。

#### ① 功率分配 1:1

| 项 | 值 |
|----|----|
| FU1 = FU2 | 175621/2 = **87811 N** |
| S22-1 | 87811 × 3.4/(3.4-1) = **124399 N** |
| 反算 S1 | 124399 − 87811 = **36588 N** |
| 第一传动滚筒合力 F1 | S22 + S22-1 = 233354 + 124399 = **357753 N** |
| 第二传动滚筒合力 F2 | S22-1 + S1 = 124399 + 36588 = **160987 N** |

#### ③ 功率分配 2:1（第44页续算）

原文按 2:1 配比继续计算传动滚筒合张力（同用 \(e^{\mu\phi}=3.4\)）。  
三种配比汇总后取：

| 项 | 值 |
|----|----|
| 第一传动滚筒最大合张力 F1max | **399 kN** |
| 第二传动滚筒最大合张力 F2max | **215 kN** |

> 注：1:2 工况下 F1 曾算到 399219 N，与 F1max≈399 kN 一致。

### 5.9 自由停车时间（续页第9节）

计算逻辑（网页必须支持）：

1. 直线平移质量 m1（含 qRO、qRU、qB、qG、L）  
2. 旋转件等效质量 m2（电机/偶合器/减速器等转动惯量 J，经传动比 i、半径 r 折算）  
3. 减速度 \(a_B=F_U^*/(m_1+m_2)\)  
4. 停车时间 \(t=v/a_B\)  
5. 再计入制动力 FZ，重算有制动停车时间  

> 需要部件转动惯量库（与表3-27及驱动装置惯量数据衔接）。

### 5.10 逆止力与逆止器选型（约第46页）

#### 逆止力
| 项 | 内容 |
|----|------|
| 逆止力 FL | **111202 N**（由前述逆止力公式算得） |
| 用途 | 上运机逆止器选型依据 |

#### 逆止器扭矩（式3-44 / 3-45）

| 项 | 公式/计算 | 结果 |
|----|-----------|------|
| 传动滚筒处逆止力矩 M'L | \(M'_L \ge F_L D / 2000\) | \(111202\times1/2000=\) **55.6 kN·m** |
| 所需逆止器力矩 ML | \(M_L \ge M'_L/(i\eta_L)\) | \(55.6/(40\times0.848)=\) **1.64 kN·m** |

> 本例 D 按 1 m、i=40、ηL=0.848（与 ZSY450-40 减速比口径一致）。

#### 选型规则（网页需实现）

| 安装位置 | 选型方向 | 本例参考 |
|----------|----------|----------|
| 高速轴 | NF 型 | 如 NF25（额定 2.5 kN·m）≥ 1.64 |
| 低速轴 | NYD 型 | 如 NYD250（额定 90 kN·m） |

#### 与制动器联动判定

- 若已设制动器，可评估是否还装逆止器  
- 规则：制动器总制动力矩 **> ML** 时，可不装逆止器（手册允许评估）  
- 本例：4 台 YWZ5-400/121，总制动力矩约 **4～8 kN·m** > 1.64 kN·m  
  → **可不另装逆止器（手册结论方向）**

> 产品里应做成可选项：高速轴逆止 / 低速轴逆止 / 仅制动器方案，并给出安全判定。
