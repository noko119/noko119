## 4. 标准计算链（对照答案）

> 公式编号来自 **DTⅡ(A) 设计手册** 用户提供页（约第42页相关章节）。

### 4.1 主要阻力 FH（式3-19）

\[
F_H = f L g [q_{RO}+q_{RU}+(2q_B+q_G)\cos\delta]
\]

| 项 | 值 |
|----|----|
| f | 0.023（多尘潮湿，表3-6） |
| qRO | 29.1 kg/m |
| qRU | 10 kg/m |
| qG | 236.1 kg/m |
| qB | 47.6 kg/m |
| L | 310 m |
| **FH** | **≈ 25525 N** |

### 4.2 特种主要阻力 FS1（式3-24 / 3-25 / 3-27 等）

- \(F_{S1}=F_\varepsilon+F_{gl}\)
- 含前倾等特种主要阻力项（μ0、Lε、ε、δ、qB、qG 等）
- **FS1 ≈ 6100 N**

### 4.3 附加特种阻力 FS2（式3-28 / 3-29）

- 清扫器等附加特种阻力
- n3=5（2个清扫器 + 2个空段清扫器；其中一个空段清扫器按1.5计）
- 查表3-11（A、p、μ3）
- **FS2 = 4200 N**

### 4.4 倾斜提升阻力 FSt（式3-31）

\[
F_{St}=q_G g H=236.1\times9.81\times57.051

- **FSt = 132138.2 N**

### 4.5 圆周驱动力 FU（式3-17）

| 项 | 值 |

## 5. 逐点张力（表3-26要点）

### 5.1 起算与方法

- 按不打滑条件，传动滚筒奔离点最小张力取 **S1 = 24946 N**
- 沿运行方向逐点累加（点号约 S1～S22）
- 表列四种计算列：
  1. 按不打滑条件计算
  2. **1:1 双传动**
  3. **2:1 双传动**
  4. **1:2 双传动**

### 5.2 关键规则（已从原文确认）

- 若干相邻点张力相等或按系数传递，例如：`S1=S2`，`S3=S4=1.03×S2` 等
- 回程/局部段含：`f Li g (qRU+qB)`、清扫器阻力 `1.5 Fr` 等
- **2:1 双传动**时：若 `S13 < F承min`，则强制 `S13 = 41746 N`

### 5.3 双驱功率分配与滚筒合力（原文算例）

包角摩擦项取 \(e^{\mu\phi}=3.4\)（原文简化）。

#### ① 功率分配 1:1

| 项 | 值 |
|----|----|
| FU1 = FU2 | 175621/2 = **87811 N** |
| S22-1 | 87811 × 3.4/(3.4-1) = **124399 N** |
| 反算 S1 | 124399 − 87811 = **36588 N** |
| 第一传动滚筒合力 F1 | S22 + S22-1 = 233354 + 124399 = **357753 N** |
| 第二传动滚筒合力 F2 | S22-1 + S1 = 124399 + 36588 = **160987 N** |

#### ③ 功率分配 2:1（第44页续算）

原文按 2:1 配比继续计算传动滚筒合张力（同用 \(e^{\mu\phi}=3.4\)）。  
三种配比汇总后取：

| 项 | 值 |
|----|----|
| 第一传动滚筒最大合张力 F1max | **399 kN** |
| 第二传动滚筒最大合张力 F2max | **215 kN** |

> 注：1:2 工况下 F1 曾算到 399219 N，与 F1max≈399 kN 一致。
