## 4. 标准计算链（对照答案）

### 4.1 主要阻力 FH

\[
F_H = f L g [q_{RO}+q_{RU}+(2q_B+q_G)\cos\delta]
\]

| 项 | 值 |
|----|----|
| f | 0.023（多尘潮湿，表3-6） |
| qRO | 29.1 kg/m |
| qRU | 10 kg/m |
| qG | 236.1 kg/m |
| qB | 47.6 kg/m |
| L | 310 m |
| **FH** | **≈ 25525 N**（由上式算完，并与下文 FU 闭合） |

### 4.2 特种主要阻力 FS1

- \(F_{S1}=F_\varepsilon+F_{gl}\)
- **FS1 ≈ 6100 N**

### 4.3 附加特种阻力 FS2

- 含清扫器等，n3=5（2个清扫器 + 2个空段清扫器，其中一个空段清扫器按1.5计）
- **FS2 = 4200 N**

### 4.4 倾斜提升阻力 FSt

\[
F_{St}=q_G g H=236.1\times9.81\times57.051
\]

- **FSt = 132138.2 N**

### 4.5 圆周驱动力 FU

\[
F_U=C F_H+F_{S1}+F_{S2}+F_{St}
\]

| 项 | 值 |
|----|----|
| C | 1.30（表3-5） |
| **FU** | **≈ 175621 N** |

闭合核验：

`1.30×25525 + 6100 + 4200 + 132138.2 ≈ 175621` ✓

## 5. 逐点张力（表3-26要点）

### 5.1 起算与方法

- 按不打滑条件，传动滚筒奔离点最小张力取 **S1 = 24946 N**
- 沿运行方向逐点累加（点号约 S1～S22）
- 表列四种计算列：
  1. 按不打滑条件计算
  2. **1:1 双传动**
  3. **2:1 双传动**
  4. **1:2 双传动**

### 5.2 关键规则（已从原文确认）

- 若干相邻点张力相等或按系数传递，例如：`S1=S2`，`S3=S4=1.03×S2` 等
- 回程/局部段含：`f Li g (qRU+qB)`、清扫器阻力 `1.5 Fr` 等
- **2:1 双传动**时：若 `S13 < F承min`，则强制 `S13 = 41746 N`

### 5.3 双驱功率分配与滚筒合力（原文算例）

包角摩擦项取 \(e^{\mu\phi}=3.4\)（原文简化）。

#### ① 功率分配 1:1

| 项 | 值 |
|----|----|
| FU1 = FU2 | 175621/2 = **87811 N** |
| S22-1 | 87811 × 3.4/(3.4-1) = **124399 N** |
| 反算 S1 | 124399 − 87811 = **36588 N** |
| 第一传动滚筒合力 F1 | S22 + S22-1 = 233354 + 124399 = **357753 N** |
| 第二传动滚筒合力 F2 | S22-1 + S1 = 124399 + 36588 = **160987 N** |

#### ② 功率分配 1:2

| 项 | 值 |
|----|----|
| FU1 | 175621/3 = **58540 N** |
| FU2 | 2×175621/3 = **117081 N** |
| S22-1 | 117081 × 3.4/(3.4-1) = **165865 N** |
| 反算 S1 | 165865 − 117081 = **48784 N** |
| 第一传动滚筒合力 F1 | 233354 + 165865 = **399219 N** |

> 锚点：**S22 = 233354 N**（用于上述合力计算）
