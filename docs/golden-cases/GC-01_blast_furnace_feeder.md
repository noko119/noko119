## 4. 标准计算链（对照答案）

### 4.1 主要阻力 FH

\[
F_H = f L g [q_{RO}+q_{RU}+(2q_B+q_G)\cos\delta]
\]

| 项 | 值 |
|----|----|
| f | 0.023（多尘潮湿，表3-6） |
| qRO | 29.1 kg/m |
| qRU | 10 kg/m |
| qG | 236.1 kg/m |
| qB | 47.6 kg/m |
| L | 310 m |
| **FH** | **≈ 25525 N**（由上式算完，并与下文 FU 闭合） |

### 4.2 特种主要阻力 FS1

- \(F_{S1}=F_\varepsilon+F_{gl}\)
- **FS1 ≈ 6100 N**

### 4.3 附加特种阻力 FS2

- 含清扫器等，n3=5（2个清扫器 + 2个空段清扫器，其中一个空段清扫器按1.5计）
- **FS2 = 4200 N**

### 4.4 倾斜提升阻力 FSt

\[
F_{St}=q_G g H=236.1\times9.81\times57.051
\]

- **FSt = 132138.2 N**

### 4.5 圆周驱动力 FU

\[
F_U=C F_H+F_{S1}+F_{S2}+F_{St}
\]

| 项 | 值 |
|----|----|
| C | 1.30（表3-5） |
| **FU** | **≈ 175621 N** |

闭合核验：

`1.30×25525 + 6100 + 4200 + 132138.2 ≈ 175621` ✓

### 4.6 传动功率与电机

| 项 | 值 | 说明 |
|----|----|------|
| 轴功率 PA | ≈ 351.2 kW | \(P_A=F_U v/1000\) |
| 效率 η | 0.88 | η=η1·η2 |
| 电动机总功率需求 | ≈ 399.1 kW | \(P_M=P_A/\eta\) |
| 运行策略 | 正常 3 台工作 | 双滚筒四电机配置 |
