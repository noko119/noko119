## 减震怎么优化（整环一件）

以②为主，结合③剖视看到的槽/孔信息：

```text
① 端面：少而深的盲孔（改过密小孔）
② 外圆：防转凸筋 → 轴承座槽
③ 内孔：周向减震筋抱轴承外圈
④ 内台阶：保留，挡外圈
⑤ 材料：PA66+GF；外圈不得碰硬座
```

```text
外圈振动 → 减震筋吸能 → 套体阻尼 + 盲孔耗声 → 轴承座（削弱）
```

黄封公、红唇满脂、深蓝热补偿先不动。
