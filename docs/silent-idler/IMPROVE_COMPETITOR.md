# 竞品静音托辊 → 更静音改进

> 对象：双层管 + 青绿端座硬装轴承 + 黄/紫软迷宫。  
> 只保留示意图与说明。

![改进对比示意](./figures/17-improve-schematic-only.jpg)

---

## 别人家哪里吵

轴承外圈直接硬装在青绿端座里，振动一路传到管体，管体像鼓一样响。黄/紫软迷宫主要挡灰，**几乎不隔振**。

## 怎么改更静

在绿色轴承外圈和青绿端座之间加一层 **尼龙降噪座**——这是主静音件，用来切断「轴承 → 管体」硬传振。

软迷宫保留（不刮轴），齿缝收到约 **0.3～0.6 mm** 并满脂；最外可加一道轻贴软唇；端座与管之间可加薄阻尼层；端盖与支架留间隙 **δ**，不要碰擦。轴承用低噪声级（Z2/Z3、C3）。

```text
支架 |δ| 端盖 → 软唇 → 软迷宫（满脂）→ 轴承 → ★尼龙座★ → 端座 →（阻尼）→ 双层管
轴固定入支架槽
```

## 图注对照

| 颜色/零件 | 说明 |
|-----------|------|
| 棕外套 + 蓝内衬 | 双层管，可保留 |
| 青绿端座 | 承力座；轴承不要再硬装在它孔里 |
| 绿色轴承 | 外圈只进尼龙座 |
| 灰蓝尼龙座 | **主静音**：隔振 |
| 黄定子 / 紫转子 | 软迷宫防尘，非接触 + 满脂 |
| 软唇 | 最外一道轻贴，不伤轴 |
| δ | 端盖与支架间隙，严禁碰擦 |
