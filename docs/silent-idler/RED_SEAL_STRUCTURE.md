## 结构就是这样

```text
红密封（NBR/TPE 一体注塑）
├─ ① 压入肩 —— 外圆过盈进紫封母槽（随辊转）
├─ ② 隔腔筋 ×3 —— 围出 3 个脂腔；内径 = 轴径 + 2δ（不压轴）
└─ ③ 最外软唇 —— 唯一贴轴，轻贴防尘
```

| 参数 | 建议（Φ159） |
|------|----------------|
| 轴向长 Lr | 12～20 mm |
| 近轴间隙 δ | 0.2～0.5 mm |
| 材料 | NBR / TPE，邵氏 A 55～70 |
| 脂 | 三腔 **灌满**（防尘 + 端部隔音） |

**不是**四道都死压轴的 V 唇叠罗汉；**是**杯形环 + 内隔板储脂 + 一道外唇。

装配：黄封公上轴 → 紫封母套入 → 红件轴向压槽 → 注脂孔灌满三腔。
