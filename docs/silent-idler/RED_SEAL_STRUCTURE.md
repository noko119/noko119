# 红色密封 · 结构（各视图）

> 合理结构：**一件软质红密封**压入紫封母槽；内 **3 个满脂腔**（近轴间隙）+ **最外 1 道软唇**轻贴轴。  
> 只保留示意图与说明。

## 它长什么样

| 视图 | 看什么 |
|------|--------|

| **② 端面** | 环状一件，内孔留 δ，唇口朝轴 |

---

## 结构要点

```text
紫封母内槽
  └─ 红密封（NBR/TPE 一体注塑）
       ├─ 外圈压入肩 → 紫槽过盈定位
       ├─ 隔腔 1～3 → 腔间满润滑脂，筋近轴间隙 δ≈0.2～0.5 mm
       └─ 最外软唇 → 单独轻贴轴（防尘）
```

| 部位 | 作用 |
|------|------|
| 3 个脂腔 | 防尘曲路 + **端部隔音**（满脂） |
| 近轴间隙 | 不四道死压轴，少啸叫 |
| 最外软唇 | 最后一道防尘 |
| 压入肩 | 跟紫件一起转，不窜 |

材料：软 **NBR** 或 **TPE**，邵氏 A 约 **55～70**。  
轴向长度 **Lr ≈ 12～20 mm**（Φ159 端组，见 [`PHI159_AXIAL_LENGTHS.md`](./PHI159_AXIAL_LENGTHS.md)）。

---

## 装配

1. 黄封公已上轴，紫封母套入  
2. 红密封从外侧**轴向压入**紫件槽（压入肩过盈）  
3. **各腔灌满润滑脂**（可从紫件外缘注脂孔补脂）  
4. 验收：转灵活、无啸叫、脂不空、外唇轻贴  

改进原则仍见 [`RED_SEAL_IMPROVE.md`](./RED_SEAL_IMPROVE.md)（满脂保留，少死压）。
