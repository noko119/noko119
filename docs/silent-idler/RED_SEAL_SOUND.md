# 红色密封能隔音吗？

> 依据你 CAD 里橙/红色多齿迷宫密封。  
> 只保留示意图与说明。

![红密封不能隔音](./figures/21-red-seal-not-soundproof.jpg)

---

## 结论

**不能。** 红色密封（迷宫齿）**不是隔音件**。

齿与对偶件之间有缝（约 0.3～0.6 mm，常满脂），空气/声波能绕过去；它挡的是灰和水和粗颗粒，不是把声音封死。

---

## 它实际干什么

| 能做 | 不能做 |
|------|--------|
| 防尘、防水、挡粗颗粒 | **隔音 / 隔声波** |
| 非接触（或软唇轻贴）→ 少摩擦啸叫 | 代替尼龙座去隔振 |
| 满脂后防尘更好，略增粘滞 | 让管体不再鼓响 |

```text
错：红密封把声音封住 → 更静音
对：红密封防尘；静音靠 尼龙座隔振 + 低噪声轴承
```

---

## 和静音的关系（别混）

- **红迷宫 / 软唇**：密封路径 → 保护轴承、少进灰，间接少坏轴承噪声  
- **尼龙座**：振动路径 → 切断轴承→管体硬传振（主静音）  
- **绿轴承选型**：振源路径 → Z2/Z3、C3、正确脂  

红件改进方向仍是：收间隙、满脂、软质不刮轴——为了**密封和少啸叫**，不是为了隔音。
