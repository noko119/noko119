# 静音托辊 · 要测哪些指标、指标多少

> Φ159 静音托辊台架/实验室验收用。  
> 噪声以**对比法**为主；跳动、阻力等对齐国标/煤标思路 + 企业精密要求。  
> 只保留说明。

---

## 一句话

必测：**噪声对比、旋转阻力、径向跳动、端盖间隙、密封（淋水/防尘后阻力）**；建议加轴向窜动、动平衡、轴承级、手感啸叫。

---

## ① 核心指标（静音相关 · 必测）

| 指标 | 怎么测 | 建议限值 / 目标 |
|------|--------|-----------------|
| **空载噪声** | 半消声舱，测点距辊 **1 m**；额定转速 | 较同规格普通辊低 **≥ 8 dB(A)** |
| **本底条件** | 关门、电机停 | 舱本底 **≤ 25 dB(A)**；且本底比测值低 **≥ 10 dB** |
| **重复性** | 同点同速测 3 次 | 偏差 **≤ 1 dB(A)** |
| **有无啸叫/碰擦** | 耳听 + 观察 | **无周期性啸叫**；端盖与架**无碰擦** |

转速（Φ159）：约 **240～420 r/min**（对应带速 2.0～3.5 m/s）。  
对比铁律：同工装、同开档、同转速、同测点，只换辊。

---

## ② 运转与几何（必测 / 强建议）

| 指标 | 怎么测 | 建议限值 |
|------|--------|----------|
| **旋转阻力** | 阻力仪/拉力计（按企业台架） | **不高于**同规格优质普通辊；静音辊宜 **更低或持平** |
| **径向跳动** | 百分表（筒中部） | 企业精密档：建议 **≤ 0.5～0.7 mm**（按辊长取严；出厂按企标/MT 抽检） |
| **轴向窜动** | 轴向百分表/塞尺 | **无明显窜动**；符合企标精密托辊要求 |
| **端盖—支架间隙 δ** | 塞尺/卡尺 | **3～12 mm**；全程无碰擦 |
| **手转灵活** | 手盘筒体 | 灵活、无卡滞、无异响 |

> 跳动/阻力的绝对国标值随标准版本与辊长分档变化，出厂以现行 **GB/T 10595 / MT/T 821** 及你司企标为准；上表为静音实验室配套的**工程建议档**。

---

## ③ 密封与环境（必测抽检）

| 指标 | 怎么测 | 建议限值 |
|------|--------|----------|
| **淋水 / 防尘后** | 按 MT/T 821 或企标箱试 | 试验后旋转阻力**无明显上升**；无进水进尘失效 |
| **迷宫不接触** | 装配检查 | 定子/转子齿 **不碰刮**（间隙约 **0.3～0.6 mm** 量级） |
| **唇密封** | 装配/阻力 | 最外唇**轻贴**；禁止多唇重压导致阻力飙升 |

---

## ④ 配套件与工艺（入厂/抽检）

| 指标 | 建议要求 |
|------|----------|
| 轴承噪声级 | **Z2 / Z3**（优先 Z3） |
| 轴承游隙 | **C3** |
| 轴承充脂 | 约 **40%～60%** 腔容（按工艺） |
| 筒体动平衡 | 整辊动平衡合格（企标档） |
| 减震座 | Lg = 轴承宽度 B；外端面与轴承外端面齐平 |

---

## ⑤ 实验室本身（测辊前先过）

| 指标 | 限值 |
|------|------|
| 舱本底 | ≤ 25 dB(A) |
| 电机隔间影响 | 主舱增量 &lt; 3 dB(A) |
| 围护隔声 | Rw ≥ 45 dB |

见 [`SILENT_LAB_STANDARD.md`](./SILENT_LAB_STANDARD.md)。

---

## ⑥ 验收怎么判“静音辊合格”

1. 噪声 ΔL = L普通 − L静音 **≥ 8 dB(A)**，且无啸叫碰擦  
2. 旋转阻力 ≤ 对比优质辊  
3. 径向跳动 / 窜动在企标内  
4. δ = 3～12 mm，无碰架  
5. 密封抽检后阻力不明显恶化
