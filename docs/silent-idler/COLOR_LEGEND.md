# 你 CAD 颜色对照

> 只说明颜色是什么，避免和示意图里的「脂」搞混。

| 颜色 | 是什么 | 干什么 |
|------|--------|--------|
| **金黄 / 黄件** | **密封保持架（载体）** | 托住红色唇/迷宫，装在轴与紫件之间 |
| 红色 | 软质密封唇 / 迷宫齿 | 防尘；齿间可满脂 |
| 浅黄点/涂脂（示意用） | **润滑脂**（不是零件） | 防尘 + 端部隔声 |
| 绿色 | 轴承隔音套 | 结构隔振、吸声 |
| 深蓝 | 软质热补偿件 | 消除热变形 |
| 轴承本体（青/灰） | 深沟球轴承 | 回转 |
| 紫 / 青绿大件 | 端盖、端座壳体 | 承力、封装 |
| 棕 | 实心轴 | 承力、固定贯通 |

**一句话：** 你图里那块实心金黄色 = **黄件保持架**；不是轴承球，也不是油脂本身。脂是填在红唇/迷宫缝里的。
