# 你 CAD 颜色对照（已纠正）

> 之前把金黄说成「保持架」是错的。

| 颜色 | 是什么 | 转不转 | 干什么 |
|------|--------|--------|--------|
| **金黄** | **迷宫定子 / 封公** | **不转**（装在轴上） | 轴上密封件：与紫件形成迷宫；立边可靠近轴承内圈作轴向挡 |
| **紫色** | **迷宫转子 / 封母**（或端盖侧密封） | **转**（随辊/座） | 与黄定子齿/腔交错 |
| **红色** | 软质唇 / 迷宫齿（软材） | 相对运动 | 防尘；齿间满脂 → 端部隔声 |
| 浅黄点（仅示意） | 润滑脂（不是零件） | — | 填在红/黄/紫形成的腔里 |
| 深绿 | 聚合物端座本体 / 隔振套本体 | 随辊转 | 承力+阻尼壳体 |
| **浅绿** | **减震筋**（座内孔凸起） | 随座 | **顶住轴承外圈**：径向定位+隔振；外圈不贴满深绿壁 |
| 绿色（统称） | 隔音/减震相关件 | 随座转 | 见上两行，勿把浅绿当成另一零件 |
| 深蓝 | 软质热补偿件 | — | 消除热变形 |
| 轴承（青/灰） | 深沟球轴承 | 外圈转/内圈固定 | 回转 |
| 青绿大壳 | 端座壳体 | 转 | 承力 |
| 棕 | 实心轴 | **不转** | 承力贯通 |

```text
金黄（封公/定子）──装轴上──不转
紫色（封母/转子）──随辊转
红色软唇 + 脂 ── 在黄紫之间做防尘和脂腔隔声
```

**一句话：金黄色 = 轴上的迷宫定子（封公），不是保持架，不是脂，不是滚珠。**
