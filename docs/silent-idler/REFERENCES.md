# 静音托辊方案 — 依据与参考出处

> 本文说明 `DESIGN.md` 中各结构主张的**出处层级**与可核对文献。  
> 本方案是对**现行标准 + DTⅡ 通用结构 + 国际厂商成熟做法**的工程综合，**不是**某一家产品的抄图，也不是未公开试验报告的复述。

---

## 0. 怎么读这份出处表

| 证据等级 | 含义 | 用法 |
|----------|------|------|
| **A 标准条文** | 国标/行标/协会标准有明文 | 应优先遵守；数字以标准为准 |
| **B 设计手册 / 系列型谱** | DTⅡ(A) 等行业通用设计资料 | 国内散料皮带机默认骨架 |
| **C 厂商公开技术资料** | 样本、白皮书、协会技术报告 | 证明“业界已这样用” |
| **D 工程惯例 / 综合取值** | 多家做法归纳或安装几何推导 | 须在详细设计中按开档/公差核算，不能当标准硬指标 |

**诚实边界：**

- 方案中的“约降噪 8～15 dB(A)”“迷宫间隙 0.3～0.6 mm”“端盖—支架间隙 3～12 mm”等，属 **D 级经验/综合区间**，公开标准一般**不直接规定**这些静音结构尺寸。  
- 轴承噪声分组 **Z2/Z3** 是轴承工业常用噪声等级表述（配套厂商样本），不是 GB/T 10595 对托辊的强制条款。  
- 早期示意图曾把端盖画得像接到支架上，属示意错误；动静件与支架衔接以修正图及本文映射为准。

## 1. 结构主张 → 出处映射

| 本方案主张 | 依据摘要 | 等级 | 主要出处 |
|------------|----------|------|----------|
| 托辊基本组成：管体 + 轴 + 轴承 + 密封 | 托辊定义与组成 | A | MT/T 821-2006；GB/T 10595 |
| 轴端落入支架槽口承力；辊筒绕轴旋转 | DTⅡ / 国际通用安装方式 | B/C | 《DTⅡ(A)型带式输送机设计手册》；ISO 1537（轴端/布置尺寸） |
| **端盖不与支架承力衔接**；须留轴向空隙防碰擦 | 运动学必然 + 安装几何 | D（强约束） | 由“轴固定、筒旋转”导出；碰擦会扫膛（工程常识）。间隙具体值按开档/辊长公差核算 |
| 冲压轴承座 + 管体焊接 | 国内主流辊子结构 | B | DTⅡ(A) 辊子结构说明（冲压轴承座、迷宫密封） |
| **迷宫（非接触）密封为主**；内外密封件不得相互接触 | 标准明确迷宫充脂、非接触装配 | A | GB/T 10595（迷宫式密封充脂）；MT/T 821-2006 §3.4.6「安装迷宫密封件时，内、外密封件不得相互接触」 |
| 接触式密封唇口完好、可作辅助 | 标准区分接触/非接触密封及试验限值 | A | MT/T 821-2006（接触式密封装配与浸水/淋水限值更严） |
| 轴承与迷宫充 **2 号锂基脂**；轴承空隙充脂约 **40%～60%**（恶劣工况更高）；密封间隙应充满 | 国标装配要求 | A | GB/T 10595（托辊装配充脂条款；脂性能不低于 GB/T 7324 2 号锂基脂） |
| 恶劣工况选性能良好的密封；噪声敏感区宜用低噪声托辊 | 工程标准选型要求 | A | GB 50431-2020 §8.3.2（密封按环境选；临近噪声控制区宜采用低噪声托辊） |
| 多级迷宫 + 外层防护是北美/欧厂商主流 | 厂商公开结构 | C | Martin Sprocket triple labyrinth；MANTIS 多层 labyrinth；Rulmeca 迷宫端盖系列 |
| 精密/优质轴承可显著降低托辊噪声 | 协会技术报告 | C | CEMA Technical Report 2007-01 *Noise Considerations for Conveyor System Design and Application* |
| 静音加强：聚合物端盖、内部隔振/消音 | 厂商静音辊产品 | C | Rulmeca 117/HS（internal soundproofing）、117 系列 PA 端盖 + PP 迷宫罩 |
| 辊径系列 Φ89/108/133/159/194 等 | 国内系列与国际尺寸靠拢 | A/B | GB/T 10595；DTⅡ(A)；ISO 1537 直径系列 |
| 径向跳动、旋转阻力、防尘/浸水/淋水验收 | 性能与试验方法 | A | MT/T 821-2006；GB/T 10595 |
| 座—筒阻尼环、端盖降辐射噪声 | 静音加强措施 | C/D | 对标 Rulmeca 等“端盖材料 + 内部消音”；阻尼环为工程增强，非单一标准强制件 |
| 动平衡 G6.3、跳动 ≤0.5 mm 等目标 | 精密托辊/平衡惯例 | D/A 旁证 | 跳动限值以 MT/T 821、GB/T 10595 表值为准；G6.3 为 ISO 平衡品质常用档（详细设计按转速选定） |

## 2. 标准与规范（建议优先核对原文）

### 2.1 中国

| 文献 | 与本方案相关的要点 | 链接/获取 |
|------|-------------------|-----------|
| **GB/T 10595-2017**《带式输送机》 | 托辊型式参数、技术要求、试验；装配时轴承与**迷宫式密封**充脂要求 | [国家标准信息公共服务平台](https://std.samr.gov.cn/) 检索 GB/T 10595 |
| **GB 50431-2020**《带式输送机工程技术标准》 | §8.3 托辊选择：恶劣工况密封要好；**噪声控制区宜采用低噪声托辊**；性能不低于 GB/T 10595 | 建标库/标准出版渠道 |
| **MT/T 821-2006**《煤矿用带式输送机 托辊 技术条件》 | 冲压轴承座焊接；**迷宫内外件不得接触**；接触密封唇口要求；径向跳动、旋转阻力、煤尘/浸水/淋水试验 | [应急管理部公开文本示例](https://www.mem.gov.cn/fw/flfgbz/bz/bzwb/201811/P020220607351913112993.pdf)；[标准馆条目](https://ndls.cnis.ac.cn/standard/detail/1a3b132847f6b099afb7beea28ba37ea) |
| **GB/T 7324**（润滑脂） | 2 号锂基脂性能基准（由 GB/T 10595 引用） | 标准出版渠道 |
| **GB/T 990**（历史）/ DTⅡ 尺寸体系 | 托辊基本参数与尺寸（手册附录常引用） | 随 DTⅡ(A) 手册附录 |

## 5. 本方案中“数字”的出处级别（防误读）

| 数字/指标 | 在方案中的角色 | 出处级别 | 说明 |
|-----------|----------------|----------|------|
| 轴承充脂 40%～60%（恶劣更高） | 装配工艺 | **A** | 对齐 GB/T 10595；已校正早期“30%～40%”的非正式写法 |
| 迷宫内外件不接触 | 装配强制 | **A** | MT/T 821-2006 |
| 噪声敏感区用低噪声托辊 | 选型原则 | **A** | GB 50431-2020 |
| 迷宫齿间约 0.3～0.6 mm | 示意/工艺目标 | **D** | 常见非接触迷宫制造间隙量级；以厂家图样为准 |
| 端盖—支架 δ ≈ 3～12 mm | 安装防碰间隙 | **D** | 由开档、辊长、轴伸、公差反算；不是国标固定值 |
| 降噪约 8～15 dB(A) | 效果预期 | **D/C** | 相对普通辊的经验/厂商对比量级；须台架或现场对比实测 |
| 动平衡 G6.3 | 质量控制建议 | **D** | ISO 平衡品质常用档；按转速与静音等级选定 |
| 径向跳动 ≤0.5 mm | 示意目标 | **D / 对照 A** | 最终以 MT/T 821、GB/T 10595 按直径分档的表值为准 |

## 6. 建议的原文核对顺序（你要看出处时）

1. **GB/T 10595-2017** — 充脂、托辊试验与基本要求  
2. **MT/T 821-2006** — 迷宫不接触、密封试验、跳动/阻力  
3. **GB 50431-2020 §8.3** — 低噪声托辊与密封选型条文  
4. **《DTⅡ(A)型带式输送机设计手册》托辊辊子** — 冲压座 + 双迷宫的国内定型结构  
5. **CEMA TR 2007-01** — 轴承质量与噪声机理  
6. **Rulmeca 117 HS / Martin·MANTIS 迷宫样本** — 静音与多层迷宫的国际产品旁证
