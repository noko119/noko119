# 默认系数库（coeff-v0）

> 状态：**设计草稿 v0**  
> 来源：优先对齐 GC-01 / DTⅡ(A) 常用表；缺省处标「待手册表确认」  
> 版本号：`coeff-v0`（写入计算绑定）

---

## 1. 使用规则

1. 用户可覆盖任一系数；覆盖须记入方案，算入 `coeff` 版本哈希或「用户覆盖表」  
2. 正式报告列出：**默认值 / 采用值 / 来源**  
3. GC-01 回归时采用本节「GC-01 锚定值」，不以通用默认强行替代

## 5. 双驱配比枚举

| 码 | 含义 | GC-01 |
|----|------|-------|
| `1:1` | FU1=FU2 | 有 |
| `2:1` | 第一滚筒 : 第二 = 2:1 | 有 |
| `1:2` | 第一 : 第二 = 1:2 | 有 |

计算服务入参：`power_split: "1:1"|"2:1"|"1:2"`。
