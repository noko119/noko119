# DTⅡ 区段字典（十二大项 + 细分）

> 状态：**设计草稿 v0，待产品主设确认**  
> 用途：网页分类、SW 模型树命名、计算区段类型、审核汇总共用  
> 命名写入格式：`{序号两位}_{大项名}_{细分名}[_主驱动|_辅助驱动]`  
> 示例：`03_承载分支倾斜段_上运倾斜段`

---

## 1. 编码规则

| 字段 | 规则 |
|------|------|
| `major_id` | 英文短码，稳定不改（契约用） |
| `major_code` | 两位数字 01–12（展示/排序） |
| `major_name` | 中文大项名（模型树） |
| `sub_id` | `{major_id}.{n}` |
| `sub_name` | 中文细分名 |
| `kind` | `segment` 直线/弧段 · `equipment` 滚筒类设备点 |
| `branch` | `carry` 承载 · `return` 回程 · `both` · `na` |
| `geometry` | 该类需要的几何字段提示 |

---

## 2. 十二大项总表

| code | major_id | 大项名 | kind | branch |
|------|----------|--------|------|--------|
| 01 | carryH | 承载分支水平段 | segment | carry |
| 02 | carryI | 承载分支倾斜段 | segment | carry |
| 03 | retH | 回程分支水平段 | segment | return |
| 04 | retI | 回程分支倾斜段 | segment | return |
| 05 | convex | 凸弧段 | segment | both |
| 06 | concave | 凹弧段 | segment | both |
| 07 | load | 受料段 | segment | carry |
| 08 | unload | 卸料段 | segment | carry |
| 09 | trans | 过渡段 | segment | both |
| 10 | drive | 传动滚筒 | equipment | na |
| 11 | bend | 改向滚筒 | equipment | na |
| 12 | takeup | 拉紧滚筒 | equipment | na |

> 说明：01–09 对应路径区段；10–12 对应滚筒设备节点（可挂在特性点上）。

### 10 传动滚筒 `drive`

| sub_id | sub_name | 附加属性 | 计算提示 |
|--------|----------|----------|----------|
| drive.1 | 单传动滚筒 | D, 主/辅, 包角 φ, μ | 奔离点/趋入点 |
| drive.2 | 双传动滚筒 | 同上 + 配比 | 1:1 / 2:1 / 1:2 |
| drive.3 | 多滚筒驱动 | 滚筒列表 | 扩展 |

**强制规则：**

- 全线 **主驱动唯一**（`is_main_drive=true` 仅一处）  
- **奔离点 = 张力序号 1**（leave point）  
- 辅驱可多个，但须标记 `drive_role=aux`

## 4. 与路径节点类型映射（Web 编辑器）

| 编辑器 `node.type` | 默认大项 | 说明 |
|--------------------|----------|------|
| node | （用户分类区段） | 折点，本身不是大项 |
| tail | bend / 尾部 | 默认可归 bend.2 或专用尾滚筒 |
| head | bend / unload 相关 | 头滚筒常改向+卸料 |
| drive | drive | 传动 |
| bend | bend | 改向 |
| takeup | takeup | 拉紧 |

区段（两节点之间的边）必须选 `major_id` + `sub_id`。
