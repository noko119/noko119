# 皮带机 PIDM 项目规则（已定稿）

> 本文是项目架构与产品边界的强制规则。后续开发、评审、排期均以本文为准。

---

## 1. 产品形态（总规则）

**定稿：网页主应用 + SolidWorks 薄插件。**

```text
网页版（主）
  - 获客与订阅
  - 路径录入（三模式可混用）
  - 逐点张力 / 功率计算
  - 报告导出与版本冻结
  - 多角色会签

SW 薄插件（辅）
  - 登录同一账号
  - 路径同步并生成/更新总骨架
  - DTⅡ 引用分类、点序、几何提取
  - 回传数据到网页
```

### 禁止

- 禁止只做 SolidWorks 单体大插件作为唯一产品形态
- 禁止把完整计算内核只放在 SW 插件内且无法云端复算
- 禁止网页与 SW 各维护一套互不相通的路径真相

## 2. 真相源分工

| 类型 | 真相源 | 位置 |
|------|--------|------|
| 业务路径录入与方案协作 | 网页路径模块 | Web |
| 工程几何正式骨架 | SW 总骨架 | SolidWorks |
| 张力/功率计算结果 | 计算服务 | Web |
| 标准分段口径 | DTⅡ 十二大项 + 细分 | 双方共用字典 |

规则：

1. 路径可在网页录入并可视化
2. 同步进 SW 后，工程提取以 SW 骨架为准
3. 计算以服务端为准，绑定版本后冻结

## 3. 路径录入规则

路径录入主战场在 **网页**，需集成三家能力并集：

- Sidewinder：Easy/高级双模式、模板快搭、人性化交互
- Overland（Belt Analyst）：Auto Return、Advanced 承载/回程分离、Flight 表、2D 拖拽、DXF
- Helix：草绘、XYZ 坐标表、拖拽设备、比例图/3D 线架预览

### 3.1 视图与操作（已定稿）

**定稿：网页路径编辑器必须同时支持 2D 操作与 3D 操作，不是“仅 2D + 只读 3D 预览”。**

| 模式 | 能力 |
|------|------|
| 2D 操作 | 平面草绘/拖拽（俯视 XY、侧视 XZ 等）、滚筒块摆放、区段表联动 |
| 3D 操作 | 三维线架编辑：点选、空间拖拽、改高程(Z)、旋转观察、空间插点 |
| 共用数据 | 同一套节点 XYZ / 区段；2D↔3D 实时同步，禁止双真相 |

规则：

1. 用户可随时在 2D / 3D 间切换，编辑同一条路径
2. 2D 改平面坐标、3D 可改空间坐标（含高差）；表格改 XYZ 同步回视图
3. 精细工程提数仍以同步到 SW 后的骨架为准；网页不另做独立 C# CAD 主路径工具

三种录入方法允许混用：

1. 拖滚筒块自动连线
2. 表格精修（区段表 / XYZ）
3. DXF / Excel 导入

录入完成必须通过闭环检查，方可同步到 SW。

## 4. SW 薄插件职责边界

### 做

- 接收网页路径并生成/更新总骨架
- 滚筒草图块识别与属性读取（D、类型、主/辅驱等）
- DTⅡ 分类、点序（奔离点、手定1/2、其余自动）
- 托辊间距等几何提取
- 打包上传（schema + 几何版本）

### 不做

- 不做重型订阅计费与客户门户
- 不单独作为获客主入口
- 不承载完整多方案云端协作与正式报告中心

---

## 5. 网页应用职责边界

### 做

- 订阅/账号/项目空间（获客主入口）
- 路径录入可视化（2D/3D 双操作）与三模式混用
- 计算系数录入、空满载工况、主辅功率配比
- 逐点张力、功率、报告、冻结、历史对比
- 五类角色会签流程（Overland/克虏伯/响尾蛇/弗兰德/SEW）

### 不做

- 不替代 SW 做详细结构零件设计
- 不绕过 SW 直接宣称“已完成工程提数”（除非明确演示模式）

## 6. 数据与版本规则

每次正式计算必须绑定：

- schema 版本
- 几何版本
- 系数版本
- 算法版本

结果冻结后不得静默覆盖；变更需生成新版本。

发送前门禁：

- 路径闭环通过
- 必填几何完整
- 主驱动唯一且奔离点=序号1
- 契约校验通过

---

## 7. 逐步透明计算规则（强制）

**定稿：每一个计算步骤都必须算清楚、可展开、可核对。禁止只给最终黑盒结果。**

### 7.1 原则

每一步必须具备：

```text
输入 → 公式（手册编号） → 中间值 → 本步结果 → 进入下一步
```

并满足：

1. 用户可点开任一步查看完整过程  
2. 可与黄金算例（如 GC-01）逐步对照  
3. 正式报告中保留关键中间量，不只保留终值  
4. 任一步失败/超限，必须定位到该步，不得吞掉错误  

### 7.2 最少必须展开的步骤

1. 原始参数确认  
2. 区段几何（段长、倾角、高差、点序）  
3. 线密度（qG、qB、qRO、qRU）  
4. 主要阻力 FH  
5. 特种主要阻力 FS1  
6. 附加特种阻力 FS2  
7. 倾斜阻力 FSt  
8. 圆周力 FU（含系数 C）  
9. 轴功率 PA / 电机功率 PM  
10. 不打滑最小张力  
11. 下垂度最小张力  
12. 逐点张力 S1…Sn（每步公式可见）  
13. 双驱配比与滚筒合张力  
14. 选型结果（电机、减速器、拉紧、逆止等）及判定依据  

### 7.3 禁止

- 禁止只输出总功率/最大张力而隐藏中间步骤  
- 禁止跳步合并导致无法按 DTⅡ(A) 校对  
- 禁止无公式编号、无输入来源的“神秘结果”
