# 皮带机 PIDM 项目规则（已定稿）

> 本文是项目架构与产品边界的强制规则。后续开发、评审、排期均以本文为准。

---

## 1. 产品形态（总规则）

**定稿：网页主应用 + SolidWorks 薄插件。**

```text
网页版（主）
  - 获客与订阅
  - 路径录入（三模式可混用）
  - 逐点张力 / 功率计算
  - 报告导出与版本冻结
  - 多角色会签

SW 薄插件（辅）
  - 登录同一账号
  - 路径同步并生成/更新总骨架
  - DTⅡ 引用分类、点序、几何提取
  - 回传数据到网页
```

### 禁止

- 禁止只做 SolidWorks 单体大插件作为唯一产品形态
- 禁止把完整计算内核只放在 SW 插件内且无法云端复算
- 禁止网页与 SW 各维护一套互不相通的路径真相

### 1.1 大厂对标原则（强制）

**定稿：工具的所有操作与能力，必须对标国际大厂做法，取各家优点完善本工具；禁止闭门自创、与行业习惯脱节的交互。**

对标对象（能力并集，非抄袭某一家）：

| 厂商 | 代表产品 | 本工具优先吸取的优点 |
|------|----------|----------------------|
| Overland | Belt Analyst | Auto Return / Advanced 分离；2D 拖拽剖面；Flight 表；承载–回程间距；配对航段；包角/滚筒精定；改输入即重算 |
| Advanced Conveyor Technologies | Sidewinder | Easy / 高级双模式；机型与局部模板快搭；人性化向导；少步出方案 |
| Helix | Helix delta-T / CAD | 草绘中心线；XYZ 坐标表；设备拖放；比例图 + 3D 线架预览；表与图双向同步 |
| 手册/院标 | DTⅡ(A) 等 | 分段字典、逐步透明计算、可与黄金算例逐项核对 |

执行规则：

1. **全链路对标**：路径录入、回程生成、几何提取、系数录入、工况、逐点张力、功率、选型、报告、版本冻结、SW 同步——每一块的操作逻辑都要能说清「对标谁、取了什么优点」  
2. **取并集不取单家**：默认交互跟 Belt Analyst 主流程（中心线 → Auto → Advanced）；易用与模板跟 Sidewinder；草绘/表/3D 跟 Helix；计算口径跟 DTⅡ(A)  
3. **先对齐习惯，再做差异化**：差异化只能加在「透明计算、网页协作、SW 薄插件」等我们的强项上，不得牺牲大厂已验证的路径操作习惯  
4. **缺口即 backlog**：某操作大厂有、我们没有或明显难用 → 记入实现优先级，不得用「演示凑数」或「整机预制」顶替  
5. **评审口径**：新功能 / UI 变更须对照本节与 **§3.0**；说不清对标来源的交互，默认不合并进主路径

#### 禁止（对标）

- 禁止「我们自己觉得方便」但与大厂主流程冲突的路径操作（例如只能选整机预制、不能自由画中心线）  
- 禁止只对标一家而砍掉其他家已验证的刚需（如只有 Auto 无 Advanced，或只有表无图）  
- 禁止用黑盒一步出结果替代可展开的 DTⅡ 步骤（我们的差异化是更透明，不是更黑）

## 3. 路径录入规则

路径录入主战场在 **网页**。本节落实 **§1.1**：路径相关操作取三家优点并集（细节对照见下表）。

### 3.0 大厂主流程（已定稿，强制）

**定稿：主交互 = 用户自由绘制胶带中心线；不是「整机预制路径一键载入」。**

对标 Belt Analyst / Sidewinder / Helix 的共性做法：

```text
① 先画承载中心线（Carry）
② 简单回程 → Auto Return（默认，锁定跟随）
③ 复杂回程 → Advanced（用户改形：多滚筒、双驱绕行、重锤等）
④ 局部模板可插入（双驱包角、垂直重锤等）→ 插入后仍可编辑
⑤ 预制样例 / 黄金算例 → 仅演示、回归、教学；不得替代主绘制流程
```

| 能力 | 规则 | 主要对标 |
|------|------|----------|
| 承载绘制 | 用户必须能自己画出任意布置（含复杂工业线，如图3-8类），禁止只能选预制整机 | Helix 草绘 + BA 2D |
| Auto Return | **默认模式**：只画/改承载；回程自动生成并**锁定跟随**；承载变更后回程再生 | Belt Analyst Auto Return |
| Advanced | 回程可编辑；切回 Auto 须确认后再生回程（覆盖手工回程） | Belt Analyst Advanced |
| 局部/机型模板 | 可插入局部块或快搭机型；插入后并入路径，允许再改 | Sidewinder Easy/模板 |
| Flight / XYZ 表 | 图与表双向同步；可精修段长、高差、点属性 | BA Flight 表 + Helix XYZ |
| 黄金算例 / 样例 | 仅演示、回归、可选「载入示例」；**不是**主录入方式 | 自有 GC + 大厂 demo 习惯 |

#### 各家优点 → 本工具能力映射（路径）

| 能力项 | Belt Analyst | Sidewinder | Helix | 本工具目标 |
|--------|:------------:|:----------:|:-----:|------------|
| 自由画承载中心线 | ✓ | ✓ | ✓ | **必须** |
| Auto Return 锁定跟随 | ✓ | — | — | **默认** |
| Advanced 独立改回程 | ✓ | 部分 | 部分 | **必须** |
| 2D 拖拽剖面 | ✓ | ✓ | ✓ | **必须** |
| 3D 线架可编辑 | — | 部分 | ✓ | **必须**（我们加强） |
| XYZ / Flight 表 | ✓ | ✓ | ✓ | **必须** |
| Easy 模式 / 向导 | — | ✓ | — | P1 |
| 局部/机型模板可再改 | 部分 | ✓ | 部分 | P1 |
| DXF / 外部导入 | ✓ | ✓ | ✓ | P1 |
| 凸凹弧 / 最小半径辅助 | ✓ | ✓ | ✓ | P2 |
| 包角 / 滚筒精定 | ✓ | ✓ | ✓ | P2 |

#### 禁止（路径产品）

- 禁止把「一键载入整机复杂路径」当作主交互或唯一能做出复杂布置的方式  
- 禁止只有 Auto、无法 Advanced 手改复杂回程  
- 禁止局部模板插入后不可编辑、或模板等于整机不可拆改  
- 禁止用预制路径掩盖「用户画不出」的能力缺口  
- 禁止路径操作偏离 **§1.1** 已列大厂优点并集

#### 实现优先级（路径编辑）

1. **P0**：自由绘制承载中心线（2D/3D/表）+ Auto Return + Advanced 回程可改  
2. **P1**：可插入局部模板（双驱包角、垂直重锤等）且插入后可编辑；Easy/向导；DXF  
3. **P2**：大 R 凸/凹弧、滚筒 D/2 偏移与包角辅助等工业绘图增强  
4. **附带**：GC-01 等样例「载入示例」按钮（可选，非主流程）

### 3.1 视图与操作（已定稿）

**定稿：网页路径编辑器必须同时支持 2D 操作与 3D 操作，不是“仅 2D + 只读 3D 预览”。**

| 模式 | 能力 |
|------|------|
| 2D 操作 | 平面草绘/拖拽（俯视 XY、侧视 XZ 等）、滚筒块摆放、区段表联动 |
| 3D 操作 | 三维线架编辑：点选、空间拖拽、改高程(Z)、旋转观察、空间插点 |
| 共用数据 | 同一套节点 XYZ / 区段；2D↔3D 实时同步，禁止双真相 |

规则：

1. 用户可随时在 2D / 3D 间切换，编辑同一条路径
2. 2D 改平面坐标、3D 可改空间坐标（含高差）；表格改 XYZ 同步回视图
3. **网页端必须正确提取路径几何**（段长 L、高差 H、倾角 δ、水平投影 Ln、点序、滚筒属性）；提取结果可直接驱动计算，禁止用错误近似或“演示凑数”
4. 网页不另做独立 C# CAD 主路径工具；SW 用于骨架同步、装配核对与模型专有量（如布置后的托辊间距）增强，**不是**网页可以提错几何的借口
5. 路径绘制与 Auto/Advanced 行为必须符合 **§1.1 大厂对标原则** 与 **§3.0 大厂主流程**

三种录入方法允许混用：

1. 拖滚筒块自动连线
2. 表格精修（区段表 / XYZ）
3. DXF / Excel 导入

录入完成必须通过闭环检查，方可同步到 SW。

## 4. SW 薄插件职责边界

### 做

- 接收网页路径并生成/更新总骨架
- 滚筒草图块识别与属性读取（D、类型、主/辅驱等）
- DTⅡ 分类、点序（奔离点、手定1/2、其余自动）
- 托辊间距等几何提取
- 打包上传（schema + 几何版本）

### 不做

- 不做重型订阅计费与客户门户
- 不单独作为获客主入口
- 不承载完整多方案云端协作与正式报告中心

## 5. 网页应用职责边界

### 做

- 订阅/账号/项目空间（获客主入口）
- 路径录入可视化（2D/3D 双操作）与三模式混用
- **路径几何正确提取**（`pidm.extract.v0`，source=`web_path`）并驱动计算
- 计算系数录入、空满载工况、主辅功率配比
- 逐点张力、功率、报告、冻结、历史对比
- 五类角色会签流程（Overland/克虏伯/响尾蛇/弗兰德/SEW）

### 必须（几何提取）

- **网页必须正确提取** 由路径 XYZ / 节点属性可确定的全部几何与点序，写入 `pidm.extract.v0`（`source=web_path`）
- 提取公式强制：`L=‖P_to−P_from‖`，`H=z_to−z_from`，`Ln=√(dx²+dy²)`，`δ=atan2(H,Ln)`；整线 `L=ΣL_i`，`H_net`、`Ln=ΣLn_i`、`δ_eq=atan2(H_net,Ln)`
- 坐标变更后必须重提；`extract_status=stale` 时禁止正式冻结计算

### 不做

- 不替代 SW 做详细结构零件设计
- 不以 SW“尚未回传”为由降低网页提取精度或跳过网页提取

## 6. 数据与版本规则

每次正式计算必须绑定：

- schema 版本
- 几何版本
- 系数版本
- 算法版本

结果冻结后不得静默覆盖；变更需生成新版本。

发送前门禁：

- 路径闭环通过
- 必填几何完整
- 主驱动唯一且奔离点=序号1
- 契约校验通过

## 7. 逐步透明计算规则（强制）

**定稿：每一个计算步骤都必须算清楚、可展开、可核对。禁止只给最终黑盒结果。**

### 7.1 原则

每一步必须具备：

```text
输入 → 公式（手册编号） → 中间值 → 本步结果 → 进入下一步
```

并满足：

1. 用户可点开任一步查看完整过程  
2. 可与黄金算例（如 GC-01）逐步对照  
3. 正式报告中保留关键中间量，不只保留终值  
4. 任一步失败/超限，必须定位到该步，不得吞掉错误  

### 7.2 最少必须展开的步骤

1. 原始参数确认  
2. 区段几何（段长、倾角、高差、点序）  
3. 线密度（qG、qB、qRO、qRU）  
4. 主要阻力 FH  
5. 特种主要阻力 FS1  
6. 附加特种阻力 FS2  
7. 倾斜阻力 FSt  
8. 圆周力 FU（含系数 C）  
9. 轴功率 PA / 电机功率 PM  
10. 不打滑最小张力  
11. 下垂度最小张力  
12. 逐点张力 S1…Sn（每步公式可见）  
13. 双驱配比与滚筒合张力  
14. 选型结果（电机、减速器、拉紧、逆止等）及判定依据  

### 7.3 禁止

- 禁止只输出总功率/最大张力而隐藏中间步骤  
- 禁止跳步合并导致无法按 DTⅡ(A) 校对  
- 禁止无公式编号、无输入来源的“神秘结果”
