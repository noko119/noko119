# 皮带机 PIDM 项目规则（已定稿）

> 本文是项目架构与产品边界的强制规则。后续开发、评审、排期均以本文为准。

---

## 1. 产品形态（总规则）

**定稿：网页主应用 + SolidWorks 薄插件。**

```text
网页版（主）
  - 获客与订阅
  - 路径录入（三模式可混用）
  - 逐点张力 / 功率计算
  - 报告导出与版本冻结
  - 多角色会签

SW 薄插件（辅）
  - 登录同一账号
  - 路径同步并生成/更新总骨架
  - DTⅡ 引用分类、点序、几何提取
  - 回传数据到网页
```

### 禁止

- 禁止只做 SolidWorks 单体大插件作为唯一产品形态
- 禁止把完整计算内核只放在 SW 插件内且无法云端复算
- 禁止网页与 SW 各维护一套互不相通的路径真相

---

## 2. 真相源分工

| 类型 | 真相源 | 位置 |
|------|--------|------|
| 业务路径录入与方案协作 | 网页路径模块 | Web |
| 工程几何正式骨架 | SW 总骨架 | SolidWorks |
| 张力/功率计算结果 | 计算服务 | Web |
| 标准分段口径 | DTⅡ 十二大项 + 细分 | 双方共用字典 |

规则：

1. 路径可在网页录入并可视化
2. 同步进 SW 后，工程提取以 SW 骨架为准
3. 计算以服务端为准，绑定版本后冻结

---

## 3. 路径录入规则

路径录入主战场在 **网页**，需集成三家能力并集：

- Sidewinder：Easy/高级双模式、模板快搭、人性化交互
- Overland（Belt Analyst）：Auto Return、Advanced 承载/回程分离、Flight 表、2D 拖拽、DXF
- Helix：草绘、XYZ 坐标表、拖拽设备、比例图/3D 线架预览

三种录入方法允许混用：

1. 拖滚筒块自动连线
2. 表格精修（区段表 / XYZ）
3. DXF / Excel 导入

录入完成必须通过闭环检查，方可同步到 SW。

---

## 4. SW 薄插件职责边界

### 做

- 接收网页路径并生成/更新总骨架
- 滚筒草图块识别与属性读取（D、类型、主/辅驱等）
- DTⅡ 分类、点序（奔离点、手定1/2、其余自动）
- 托辊间距等几何提取
- 打包上传（schema + 几何版本）

### 不做

- 不做重型订阅计费与客户门户
- 不单独作为获客主入口
- 不承载完整多方案云端协作与正式报告中心

---

## 5. 网页应用职责边界

### 做

- 订阅/账号/项目空间（获客主入口）
- 路径录入可视化与三模式混用
- 计算系数录入、空满载工况、主辅功率配比
- 逐点张力、功率、报告、冻结、历史对比
- 五类角色会签流程（Overland/克虏伯/响尾蛇/弗兰德/SEW）

### 不做

- 不替代 SW 做详细结构零件设计
- 不绕过 SW 直接宣称“已完成工程提数”（除非明确演示模式）

---

## 6. 数据与版本规则

每次正式计算必须绑定：

- schema 版本
- 几何版本
- 系数版本
- 算法版本

结果冻结后不得静默覆盖；变更需生成新版本。

发送前门禁：

- 路径闭环通过
- 必填几何完整
- 主驱动唯一且奔离点=序号1
- 契约校验通过

---

## 7. 商业包装（与形态一致）

```text
网页订阅 = 获客与使用主体
SW 薄插件 = 专业增强连接器（可含在专业版/旗舰版）
```
