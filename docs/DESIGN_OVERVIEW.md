## 1. 本轮设计目标

先做 **技术最小闭环**，不做完整商业上线：

```text
Web 路径录入(2D/3D)
  → 分类/点序/几何
  → DTⅡ(A) 逐步透明计算（对齐 GC-01）
  → 结果可展开核对
  →（二期）同步 SW 骨架提取回传
```
