## 1. 本轮设计目标

先做 **技术最小闭环**，不做完整商业上线：

```text
Web 路径录入(2D/3D)
  → 分类/点序/几何
  → DTⅡ(A) 逐步透明计算（对齐 GC-01）
  → 结果可展开核对
  →（二期）同步 SW 骨架提取回传
```

## 3. MVP 里程碑（建议）

| 阶段 | 内容 | 完成判据 |
|------|------|----------|
| M0 设计包 | 本目录文档定稿 v0 | 字典/字段/契约/系数可评审 |
| M1 路径 | 编辑器存 JSON、闭环检查 | 导出符合 schema |
| M2 计算 | 阻力→FU→功率→S1min→逐点骨架 | GC-01 主链误差在约定内 |
| M3 透明 UI | 每步可展开：输入/公式/中间值/结果 | 对照 GC-01 逐步 |
| M4 契约联调 | SW 读同一 JSON（可先手测） | 字段对得上 |
| M5（后期） | 订阅/会签/正式报告 | 另立商业里程碑 |
