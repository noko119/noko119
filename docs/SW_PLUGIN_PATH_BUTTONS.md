# SolidWorks 插件 · 皮带机路径按钮设计（依据 DTⅡ(A) 设计手册第 2 版）

> 状态：v0 已实现（`sw-plugin/addin/`，C# Add-in，CommandManager 选项卡「DTⅡ 路径」）  
> 原则：**SW 只画路径 + 打标签；张力 / 功率 / 带强 / 选型全部在网页**（规则 `PROJECT_RULES.md`）  
> 草图形态（规则 §3.2）：**2D 侧型 / 2D 俯视 / 3D 空间** 三选一，与网页共用同一套 XYZ  
> 数据出口：`pidm.path.v0`（`WEB_SW_DATA_CONTRACT_DRAFT.md`），网页「导入 JSON(SW)」直接读取

## 0. 手册中"路径"要回答的问题 → 按钮从哪来

| 手册条目 | 它要求路径给出什么 | 对应按钮 |
|---|---|---|
| 2.3.1 侧型总体 | 承载/回程闭环，头尾滚筒、驱动、拉紧位置 | 新建路径、识别路径、Auto 回程、闭合检查、侧型模板 |
| 2.3.2 倾角 | 每段倾角 δ；一般散料 ≤18°，v>2.5 m/s 减 2°~4°，下运减 2°~4°，45°槽角可加 2°~3° | 识别路径（算 δ）→ 门禁 `MR_INCLINE` |
| 2.3.3 受料段 | 受料段尽量水平；机尾长度 l（B≤500:2000，≤800:2500，≤1200:3000，>1200:3500 mm）；凹弧起点距导料槽 <5 m 设压轮（图 2-2） | 受料段、压轮、门禁 `MR_TAIL_LEN / MR_PRESS_ROLLER` |
| 2.3.4 卸料段 | 倾斜机卸料段宜水平；v≥3.15 m/s 必须水平 | 卸料段、门禁 `MR_DISCHARGE` |
| 2.3.5 凸/凹弧 | 凸弧 >5 m 或钢绳芯 → 下分支加密托辊；凹弧禁调心托辊 | 凸弧、凹弧、门禁 `MR_CONVEX_IDLER / MR_CONCAVE_R` |
| 2.3.6 拉紧装置 | 类型（垂直重锤/车式/螺旋/绞车）、位置（中部靠近传动优先，螺旋 <30 m） | 拉紧滚筒、门禁 `MR_TAKEUP` |
| 2.3.7 过渡段 | 表 2-4 最小过渡长 A = k·B（织物 1.0/1.3/1.6，钢绳 1.8/2.6/3.4 按张力利用率） | 过渡段、线体信息（利用率）、门禁 `MR_TRANS` |
| 2.4 滚筒匹配 | 表 2-5：由传动滚筒 D 推改向滚筒 D（180°尾/中 低一档，头部探头同档，90° 低两档，<45° 低三档） | 改向滚筒（自动匹配）、门禁 `MR_DRUM_MATCH` |
| 2.5 / 表 2-7 托辊间距 | ρ≤1.6 → a0=1200，>1.6 → a0=1000；aU=3000；凸弧 1/2；受料 1/2~1/3 | 线体信息（默认）、托辊间距、凸弧（自动 1/2） |
| 3.4.3 附加阻力 | 绕带滚筒数 N1、改向滚筒数 N2（式 3-23） | 闭合检查（统计 N1/N2） |
| 3.4.4 特种阻力 | 前倾托辊段长 Lε 与 ε（式 3-25/3-26）；导料槽长 l、宽 b（式 3-27、表 3-11）；清扫器数 n（式 3-28）；犁式卸料（式 3-30） | 前倾托辊、受料段、清扫器、犁式卸料 |
| 3.5.1 围包角 | 单滚筒 190°~210°，双滚筒 ≈400° | 传动滚筒（φ）、门禁 `MR_WRAP` |
| 3.5.3 逐点张力法 | 从主传动**奔离点 S1** 起沿运行方向编号特性点；拉紧处 F0 = S趋入+S奔离 | 奔离点、手定点 1/2、特性点预览 |
| 3.10 拉紧参数 | 垂直拉紧与头部传动的 L′、H′（式 3-70）；行程 S（式 3-71） | 滚筒间距（报 L′/H′）、拉紧滚筒（S） |
| 3.11 凸凹弧半径 | 凸弧 Rmin = (38~42)·B·sinλ 织物 / (100~167)·B·sinλ 钢绳（式 3-72/3-73）；凹弧 R≥(1.3~1.5)F/(qB·g)（式 3-74，需张力→网页） | 凸弧（提示 Rmin）、凹弧（提示回填） |
| 3.13 双滚筒驱动 | 主/辅传动区分，总包角 | 传动滚筒（主/辅）、设主驱 |
| 表 3-12 摩擦系数 | 滚筒表面 → μ | 传动滚筒（表面下拉） |
| 表 13-1 常用侧型 | 12 类 × 5 剖面 = 43 种 | 侧型模板 |
| 4.8 清扫器 | 头部清扫器在卸料滚筒；空段清扫器在尾部改向前 / 垂直拉紧第一个 90° 前 | 清扫器、门禁 `MR_CLEANER` |

## 1. 按钮清单（5 组 36 个，全部已实现）

操作范式统一为：**先在草图里选对象（线段 / 折点 / 点），再点按钮 → 小对话框 → 属性写入实体**。

### 组 1 开始

| 按钮 | 做什么 | 手册 |
|---|---|---|
| 新建路径 | 建 `PIDM_PATH_SKEL`：可选 **2D 侧型（前视 XZ）/ 2D 俯视（上视 XY）/ 3D 空间**，填线体参数 B、v、ρ、带芯、槽角、间距 | 2.2、表 2-3、表 2-7 |
| 侧型模板 | 选类别 A~L + 剖面 1~5 + Ln/H/尾平/头平/R/间距/传动 D → 一键生成闭环骨架（含滚筒、拉紧、清扫器、必要压轮） | 表 13-1 |
| 线体信息 | 修改上述参数；自动刷新 a0/aU 默认值 | 表 2-7 |
| 从网页导入 | 读 `pidm.path.v0` / `pidm.bundle.v0`，重画骨架 | 契约 |

### 组 2 承载分支

| 按钮 | 做什么 | 手册 |
|---|---|---|
| 识别路径 | 直线/圆弧/样条 → 端点容差串链 → 节点序；每段算 L、H、Ln、δ；弧自动判凸/凹并取 R；写属性；方向自动纠为尾→头 | 3.4 公式输入 |
| 标为承载 / 标为回程 | 选线段改分支（Advanced 手工回程） | 2.3.1 |
| 受料段 | 单点/多点/加速段；导料槽长 l、内宽 b（表 3-11 默认）、加速段 lb、受料托辊间距 | 2.3.3、3.4.4 |
| 卸料段 | 头部 / 犁式 / 中部卸料车 | 2.3.4、式 3-30 |
| 过渡段 | 机头/机尾；提示表 2-4 最小 A | 2.3.7 |
| 前倾托辊 | ε（表 3-7 1°20′~1°35′）；段长即 Lε | 式 3-25/3-26 |
| 凸弧 | 选折点或相邻两线 → 输入 R（默认 Rmin 上限取整）→ 切点法圆化为弧段，托辊间距自动 a0/2 | 3.11.1、2.5 |
| 凹弧 | 同上；提示式 3-74 由网页回填、压轮、禁调心 | 3.11.2、2.3.3 |
| 托辊间距 | 选线段改 a0 / aU | 表 2-7 |

### 组 3 滚筒与附件

| 按钮 | 做什么 | 手册 |
|---|---|---|
| 传动滚筒 | D（系列 200~2000）、主/辅、表面→μ、围包角 φ、图号 | 表 2-6、表 3-12、3.5.1 |
| 改向滚筒 | 五类（180°尾/中/头探头、90°、<45°），D 按传动滚筒自动匹配 | 表 2-5 / 表 3-10 |
| 拉紧滚筒 | 垂直重锤 / 车式 / 螺旋 / 绞车；D；行程 S | 2.3.6、式 3-71 |
| 尾滚筒 / 头滚筒 | 快捷放置 | 2.3.1 |
| 设主驱 | 主传动唯一，奔离点 S1 自动落此 | 3.5.3.2 |
| 滚筒属性 | 修改已放滚筒 | — |
| 清扫器 | 头部 / 空段 | 4.8、式 3-28 |
| 犁式卸料 | 放点并把所在段标 unload.2 | 式 3-30 |
| 压轮 | 导料槽↔凹弧起点 | 2.3.3 图 2-2 |

### 组 4 回程与闭环

| 按钮 | 做什么 | 对标 |
|---|---|---|
| Auto 回程 | 承载折线法向偏移生成回程，首尾接头/尾滚筒 | Belt Analyst Auto Return |
| 闭合检查 | 断口、是否接回尾滚筒；N1/N2 统计 | 式 3-23 |
| 滚筒间距 | 相邻滚筒中心距 / ΔH；拉紧 L′、H′ | 式 3-70 |

### 组 5 分类与交付

| 按钮 | 做什么 | 依据 |
|---|---|---|
| 自动分类 | 分支 + 倾角 + 弧 + 标志 → `major_id/sub_id`（字典 01~12） | `DTII_SEGMENT_DICTIONARY.md` |
| 确认分类 | 人工改 sub_id → confirmed | 契约 CL_SEG_CLASS |
| 奔离点 / 手定点 1 / 手定点 2 | 张力点序 | 3.5.3.2、契约 CL_LEAVE_IS_S1 / CL_P1_P2 |
| 特性点 | 预览逐点张力法编号（只编号，不算张力） | 3.5.3 |
| 门禁检查 | 契约 CL_* 全部 + 手册 MR_* 规则 → 错误/警告/提示三级 | 见 §2 |
| 导出到网页 | `*-pidm-path-v0.json`；有 error 时只能"草稿"导出 | 契约 |
| 面板 | 任务窗格：节点/滚筒表、区段表、检查表 | — |

## 3. 表 13-1 侧型模板编号（12 类 × 5 剖面）

类别 = 驱动 / 拉紧布置；剖面 = 承载形状。代号 = 字母 + 数字（如 `C1`）。

| 类 | 驱动 / 拉紧 | 生成的滚筒 |
|---|---|---|
| A | 头部单传动 + 尾部螺旋拉紧 | 头传动(主)、尾拉紧(螺旋) |
| B | 头部单传动 + 尾部车式重锤 | 头传动(主)、尾拉紧(车式) |
| C | 头部单传动 + 头部附近垂直重锤 | 头传动(主)、尾改向、回程 90°-拉紧-90° |
| D | 头部单传动 + 增面轮 + 垂直重锤 | C + 增面滚筒 |
| E | 中部单传动（头部探头）+ 垂直重锤 | 头探头、增面改向、中部传动(主)、垂直拉紧 |
| F | 中部单传动（头部双改向）+ 垂直重锤 | E + 头部第二改向 |
| G | 中部单传动 + 车式重锤 | 头探头、中部传动(主)、车式拉紧 |
| H | 中部单传动（头部双改向）+ 车式 | G + 头部第二改向 |
| I | 头部 + 中部双传动 + 垂直重锤 | 头传动(主)、中部传动(辅)、垂直拉紧 |
| J | 头部 + 中部双传动（变体）+ 垂直重锤 | 同 I（布置变体） |
| K | 头部 + 中部双传动（变体）+ 车式 | 头传动(主)、中部传动(辅)、车式拉紧 |
| L | 中部双传动 + 垂直重锤 | 头探头、中部两传动(主+辅)、垂直拉紧 |

| 剖面 | 承载形状 | 自动生成 |
|---|---|---|
| 1 | 水平受料 → 凹弧 → 倾斜 → 凸弧 → 水平卸料 | 受料段 + 凹弧 + 凸弧 + 卸料段 + 压轮（若凹弧紧接导料槽） |
| 2 | 倾斜 → 凸弧 → 水平卸料 | 凸弧 + 卸料段 |
| 3 | 水平受料 → 凹弧 → 倾斜 | 受料段 + 凹弧 |
| 4 | 直线倾斜 | — |
| 5 | 水平 | — |

（表 13-1 原表按图号列出 43 种；此处以"类别 × 剖面"参数化覆盖，未在原表中的组合亦可生成，仅作骨架。）

## 4. SW 与网页的分界（再次明确）

| SW 插件产出（导出 JSON 里有） | 网页负责（导出 JSON 里**没有**） |
|---|---|
| 节点坐标、点序、分支、滚筒类型/D/主辅/μ/φ/拉紧类型/行程 | 逐点张力 S1…Sn、F0、Fu、功率、电机/减速器 |
| 区段 L/H/Ln/δ、sub_id、托辊间距、弧 R/θ、受料槽 l/b、前倾 ε、标志 | 阻力 FH/FN/FS1/FS2、C 系数、下垂度校核 |
| 附件位置（清扫器 n、犁式、压轮） | 凹弧 Rmin 回填校核、带强 ST/EP 选择、滚筒合力校核 |
| 特性点编号与位置、奔离点、手定点 | 张力值与图 |
| 门禁结果（几何 / 标签完整性 + 手册布置规则） | 计算门禁 |
