# 非标设计

伺服 / 步进 / 丝杠 / 齿轮齿条选型。

本篇只整理对话里这一段，与后面的托辊铝座、玻璃钢衬无关。交付物就是 Excel，公式在表内，用 Excel 或 WPS 打开。

**表：** [`伺服步进丝杠齿条选型.xlsx`](./伺服步进丝杠齿条选型.xlsx)

---

## 1. 对话里要什么

先问水平移栽：丝杠、步进、伺服怎么选。后来要一张通用表：填负载和速度，就能对照伺服和步进，带丝杠和轴承座，工艺 / 机械 / 计算机三方会审，水平、垂直、倾斜都能算。

锁定下来的做法：

- **只做 Excel，不再做网页算法。**
- 公式必须看得见，能手算核对。
- 丝杠和齿轮齿条用同一推力对照效率和电机。
- 先自动推荐，再在给定清单里手选、重算安全系数。
- 工件质量和机构质量分开填，**禁止把 640 kg 写死当架子重**（那是车架 380 + 托臂 110 + 三管 151 的估数）。
- 满速丝杠按 **直连、不加减速机**。齿条必须加减速比（直连力矩太大）。

## 2. 表怎么用

1. 只改 **输入** 页黄格和下拉。
2. 看 **推荐**：左边结果，右边公式和代入数字。
3. 看 **计算过程**：从质量、推力到丝杠/齿条转矩，共 22 步。
4. 看 **对照**：同一载荷、同一速度，丝杠 vs 齿条。
5. 采购没有该型号：输入页 **手选**，到对照页看安全系数。
6. **会审** 是工艺 / 机械 / 计算机三句意见，随计算结果变。

安装方向：水平、垂直向上、垂直向下、倾斜上坡、倾斜下坡。倾斜必须填倾角。BK/BF 只配丝杠，不要装到齿条上。

## 3. 输入默认（可改）

| 项 | 默认 | 说明 |
|---|---|---|
| 速度 | 8 m/min | 任务书上限 15，上料常用 6～8 |
| 行程 | 2500 mm | 超过约 4 m，机械侧优先齿条 |
| 加速时间 | 0.4 s | 越小加速力越大 |
| 摩擦系数 | 0.1 | 铜套约 0.1，直线导轨约 0.02 |
| 目标安全系数 | 2 | 运行力矩相对需要力矩 |
| 丝杠效率 | 0.90 | 滚珠丝杠常用 |
| 齿条 | 斜齿、η=0.94、模数 2、齿数 25 | 直齿效率改 0.90 |
| 齿条减速比 | **10** | 直连填 1；常用 8～15 |
| 减速机效率 | 0.94 | 直连（i=1）时公式按 1 计 |

## 4. 公式

工作推力：

`F = | m g sinθ + μ m g |cosθ| + m a + F外 |`

- 丝杠：`n = v×1000 / P`，`T = F·P / (2π η)`，P 为导程 mm
- 齿条：齿轮轴 `n0 = v×1000 / (π m z)`，电机 `n = n0 × i`，`T = F·(m z / 2000) / η齿 / i / η减`

水平、μ=0.1 时，约 950 N 推力、导程 10 对应转矩约 1.7 N·m（随你填的质量变）。齿条若直连、8 m/min，需要约 12.3 N·m，目录容易「无满足项」——所以默认 i=10。

## 5. 目录口径（现货优先）

丝杠优先 SFU2510 / 4010 / 2010 等；3210、3220 标现货=0，自动推荐不选，手选仍可选。BK 固定 + BF 游动，按直径配（如 4010 → BK25+BF25）。BK 内角接触、BF 内深沟球，不要拆成两套深沟球顶替。

电机：伺服 0.4～3.0 kW 带刹车；闭环步进 57 / 86 / 110 / 130。运行 SF ≥ 目标，启动 SF ≥ 1.5。慢速可用 86 闭环 12 N·m；满速 15 m/min 不推荐 0.75 kW 伺服，往 1 kW 或 110 步进靠。步进按转速掉矩。

垂直或下坡倒拖必须抱闸。行程 >4 m 优先齿条，丝杠要中间托。

## 6. 后来改过什么

- 齿条增加减速比（默认 10）和减速机效率，电机转速、转矩按 i 折算后再选。
- 推荐页同时给出公式和代入数字；完整步骤放在「计算过程」。

表还没有算：寿命、惯量匹配、丝杠挠度、具体订货号。这三项要另做，不要当这张表已经覆盖。
