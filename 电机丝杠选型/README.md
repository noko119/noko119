# 伺服 / 步进 / 丝杠 / 齿轮齿条选型（Excel）

按三位工程师口径：**只做 Excel**，公式在表内。用 Microsoft Excel 或 WPS 打开。

## 打开

`电机丝杠选型/伺服步进丝杠齿条选型.xlsx`

需要重生成时：

```bash
python3 电机丝杠选型/build_xlsx.py
```

## 用法

1. 只改 **输入** 页黄格和下拉  
2. 看 **推荐**：左边是结果，右边是公式和代入数字  
3. 看 **计算过程**：从质量、推力到丝杠/齿条转矩的完整 22 步  
4. 看 **对照**（丝杠 vs 齿条效率和电机）  
5. 没有该型号：在输入页 **手选** 给定清单，对照页会跟手选走  
6. **会审** 为工艺 / 机械 / 计算机意见  

安装方向：水平、垂直向上、垂直向下、倾斜上坡、倾斜下坡。  
工件质量和机构质量分开填。齿条默认减速比 **10**（直连填 1）。BK/BF 只配丝杠。
