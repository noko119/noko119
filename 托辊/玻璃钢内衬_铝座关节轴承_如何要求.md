# 玻璃钢内衬如何要求（铝座 + 关节轴承）

结构：UHMWPE 5 mm / 衬 Φ184×730 / 两端铝座压入 Φ175 / 座内 6211 + GE35 / 轴 Φ35。

**分工（写进订货说明，免得供应商按钢管或按空心衬理解）**

| 谁 | 负责 | 玻璃钢不要扛的 |
| --- | --- | --- |
| 铝座 | 6211 外圈圆度、座孔 Φ100 | 4.5 mm 止口壁单独撑圆 |
| GE35 | 端斜、轴 Φ35 | 管体压扁 |
| 玻璃钢衬 | 中间承弯、套住铝座、20 kN 台阶、与 UHMWPE 不转套、两止口同心 | 6211 寿命、GE 是否转动 |

---

## 订货 / 图纸上就写这些（玻璃钢）

未注 GB/T 1804-m、GB/T 1184-K。纤维缠绕，无碱纱 + 间苯或乙烯基酯。**禁止短切毡单独承力。**

**材质（随炉样或剖管）**

| 项 | 要 |
| --- | --- |
| 玻纤含量 / 固化度 / 巴氏 | ≥55% / ≥90% / ≥40 |
| 环向拉伸 / 模量 | ≥180 MPa / **≥20 GPa** |
| 轴向拉伸 / 模量 | ≥80 MPa / **≥12 GPa** |
| 层间剪切 | ≥15 MPa |
| 环刚度 SN | ≥20 kN/m² |
| 冲击 | ≥80 kJ/m² |
| 吸水 24 h | ≤0.5% |
| 井下 | 电阻 ≤1×10⁸ Ω，喷灯续燃/阴燃 ≤5 s |

环向层 ≥60%。止口加工后剩余环向层 ≥2.5 mm。

**尺寸**

- Φ184 0/−0.30，长 730 0/−1.0  
- 止口 Φ175H9 × 深 62 ±0.20（座+密封不够深就改座图，不许硬挤）  
- 止口壁 4.5 ±0.25；**中间必须加厚**，台阶径向宽 **≥3 mm**（中间内径 ≤169）  
- 台阶根部 R0.8～1.5；孔口 2×15°；切口封脂  

**形位（基准 = 两止口公共轴）**

- 两 Φ175 同轴 **φ0.12**（一次装夹）  
- 止口圆度 0.05；压入铝座后圆度 **≤0.08**  
- 外圆对孔轴跳动 0.25；直线度 0.40  
- 台阶对轴线垂直 0.10  

**装铝座以后才算数的（衬的验收要点）**

1. 铝座过盈 0.05～0.15 + 结构胶 + 台阶挡，不许只靠过盈。  
2. 轴向 **20 kN** 台阶不分层、座不脱出。  
3. 跨中挠度 **≤0.67 mm**（跨距/1000；端斜由 GE 吃，不按 6211 的 0.50 mm）。  
4. 工作载荷下**中间**外圆椭圆 **≤0.20 mm**（GE 不管压扁）。  
5. 与 UHMWPE 剥离 ≥50 N/25 mm，不得转套。  
6. 6211 圆度看铝座孔 **≤0.02 mm**，不要拿空心 Φ175 当 6211 的圆。

**逐根：** 外径、止口、巴氏、外观、两孔同轴。  
**每批：** 环向模量或 SN、层间剪切、装座后 20 kN、中部椭圆。  
**换配方：** 全项 + 阻燃抗静电。
