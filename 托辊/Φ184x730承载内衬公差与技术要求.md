# 承载内衬（玻璃钢）— 力学性能、尺寸公差、形位公差、技术要求

件名：承载内衬  
材质：**玻璃钢（GFRP，玻璃纤维增强热固性塑料）**，不是钢衬，也不是短纤注塑件。  
图示：外径 **Φ184**，全长 **730**，两端止口 **Φ175 × 深 62**。本孔配轴承座外圆，**不装 6211**。  
未注尺寸 **GB/T 1804-m**，未注形位 **GB/T 1184-K**。

外面 UHMWPE 管体 750、包覆若按 736，本衬 730，两端相对管体各缩进约 10 mm。止口处壁厚名义 4.5 mm。玻璃钢台阶怕的是**分层**，不是屈服；台阶径向宽度仍须 **≥3.0 mm**（中间内径 ≤169）。

---

## 1. 力学性能（本件要写进图样 / 采购规范）

工艺：**纤维缠绕**（环向层 + 交叉层）。树脂用间苯或不饱和聚酯、乙烯基酯；增强用无碱玻纤纱。禁止正交无纬毡/短切毡单独做承力层（模量不够，6211 会被压椭圆）。阻燃抗静电剂允许加，但下表力学仍须达标。

### 1.1 材料试样（从本衬管壁取样，或同工艺随炉样）

环向按 **GB/T 5351**（管环向拉伸），轴向按 **GB/T 5349**，压缩 **GB/T 5350**，弯曲 **GB/T 1449**，层间剪切 **GB/T 1458**（短梁），冲击 **GB/T 1451**，平行板环刚度 **GB/T 5352** 或 **GB/T 9647**，巴氏 **GB/T 3854**，含胶/含纤 **GB/T 2577**，固化度 **GB/T 2576**，吸水 **GB/T 1462**。

| 项目 | 指标 | 为什么定这个数 |
| --- | --- | --- |
| 密度 | 1.70～1.95 g/cm³ | 过低则树脂多、模量差；过高则夹砂/填料过多 |
| 结构层玻纤质量含量 | **≥55%** | 缠绕管常规 60%～75%；低于 50% 当塑料管用 |
| 树脂不可溶分（固化度） | **≥90%** | 欠固化则蠕变、掉巴氏、遇水掉强度 |
| 巴柯尔硬度 | **≥40** | 固化判定；低于 35 不许装配 |
| 孔隙率 | **≤3%** | 分层和进水的源头 |
| **环向拉伸强度** | **≥180 MPa** | 保止口圆、抗带面压扁；阻燃配方会掉点，180 是底 |
| **环向拉伸模量** | **≥20 GPa** | 4.5 mm 壁要撑住座和 6211。短切毡大约只有 8 GPa，不许 |
| **轴向拉伸强度** | **≥80 MPa** | 跌落、搬运弯管；静载 20 kN 对净截面只有约 8 MPa，真正怕冲击 |
| 轴向拉伸模量 | **≥8 GPa** | 交叉层不能省 |
| 轴向压缩强度 | **≥120 MPa** | 台阶承座、20 kN 轴向 |
| 纵向弯曲强度 | **≥150 MPa** | GB/T 1449 |
| 纵向弯曲模量 | **≥12 GPa** | |
| **层间剪切强度** | **≥15 MPa** | 台阶和止口加工后最容易从此裂 |
| 简支梁冲击韧性 | **≥80 kJ/m²** | 玻璃钢脆，要对齐 MT 821 跌落 |
| **初始环刚度 SN** | **≥20 kN/m²** | 平行板，挠度 3%。本规格壁 4.5、环向模量 20 GPa 约可到 SN30；给 20 是底 |
| 吸水率（23 ℃，24 h） | **≤0.5%** | |
| 浸水 24 h 后环向强度保留 | **≥85%** | 井下淋水 |
| 80 ℃ 弯曲强度保留 | **≥70%** | 树脂耐热；外层 UHMWPE 本身也不超过约 80 ℃ |

环向层占结构层厚度 **≥60%**，其余为交叉缠绕（建议 55°～70°）提供轴向和抗冲击。两端止口 62 mm 区环向加厚，精加工后**剩余环向层厚度 ≥2.5 mm**，不许车穿只剩富树脂层。

### 1.2 整根内衬（构件，按本图尺寸做）

这些是玻璃钢衬自己要过的，和成辊 MT 821 对齐，但在装 UHMWPE、装座之前就可以筛废品。

| 项目 | 试验 | 指标 |
| --- | --- | --- |
| 径向抗压（抗椭圆） | 平行板，中部加压 **2500 N**，保载 1 min，卸载 | Φ184 残余椭圆（Dmax−Dmin）**≤0.20 mm**；两端 Φ175 圆度仍 **≤0.08 mm**，无白斑、无分层 |
| 径向蠕变 | 常温，中部 **1500 N** 连续 **72 h** | 卸载后残余椭圆增量 **≤0.15 mm**。玻璃钢和钢的差别就在这里，不做这条，井下会慢慢塌圆、卡轴承 |
| 轴向承载 | 两端经模拟座（Φ175 止口贴合台阶）缓慢加到 **20 kN**，保载 1 min | 台阶不压溃、不分层、管体不裂；与 MT 821 表4（Φ194）同一载荷 |
| 止口压装 | 配轴承座压入（过盈按座图，宜 **0.05～0.15**，胶接辅助） | 压入后 Φ175 圆度 **≤0.08 mm**，外圆圆度 **≤0.25 mm**，孔壁不掉渣、不分层 |
| 跌落（衬本身抽检） | 水平，中心线离水泥地 **1 m**，一次 | 无穿透裂纹、无明显分层；再测两端孔同轴仍 **φ0.15** 内 |
| 与 UHMWPE 结合 | 外圆滚花/环槽 + 热熔或结构胶 | 剥离 **≥50 N/25 mm**；周向不得相对转动。须能随成辊过 1 m 跌落和 20 kN |

成辊装完后仍按 **MT 821—2006**：径向跳动 ≤1.2 mm，阻力（非接触）≤3.5 N，轴向 20 kN，跌落、密封、寿命。本衬力学不够，那些一项都过不去。

### 1.2.1 挠度（对标同规格钢衬）

标准没有托辊衬挠度条文。基准按 **同外形钢衬** 计算，再给玻璃钢允许值。

计算条件：外径 Φ184，止口壁 4.5 mm（内径 175），两端简支，跨距 **670 mm**（两轴承中心），均布载荷，钢 E=2.06×10⁵ MPa。

| 径向工作载荷 | 钢衬跨中挠度 | 同壁厚玻璃钢（轴向 E=12 GPa） |
| --- | --- | --- |
| 14 kN（本方案 6211，2.0 m/s、20 000 h） | **0.026 mm** | 约 0.45 mm |
| 18 kN（6407 对标辊同工况） | **0.034 mm** | 约 0.58 mm |

钢衬挠度可忽略，玻璃钢同壁厚大约是钢的 **E钢/E玻≈17 倍**。外径锁在 184，玻璃钢即使做成实心也做不到和钢同一毫米数（EI 对不上）。

**图样按下面写（带 GE35 关节轴承，对标钢衬）：**

有关节轴承时，管体弯曲造成的端斜由 **GE 吸收**（许用摆角 6°），**不要再按 6211 偏斜 8′ 卡 0.50 mm**。GE 在 0.67 mm 挠度下端斜大约 **0.18°**，远小于 6°。

| 项目 | 玻璃钢衬 | 对标关系 |
| --- | --- | --- |
| 跨中弯曲挠度 | **≤ 跨距/1000 = 0.67 mm** | 与钢管厂检同一条。钢衬 14 kN 时只有 0.026 mm，必过；玻璃钢按同一条卡 |
| 工作载荷下外圆椭圆 | **Dmax−Dmin ≤0.20 mm** | 钢衬≈0。关节轴承**不管**压扁，这条不能放宽 |
| 止口 Φ175 圆度 | **≤0.08 mm** | 保证 6211 外圈不扁 |

载荷用 6211 反算径向工作力（均布）。轴向模量 12 GPa、中间加厚到台阶宽 ≥3 mm 时，14 kN 下弯曲挠度大约 0.45 mm，能过 0.67 mm。椭圆仍要靠环向模量和壁厚，与有没有关节轴承无关。

### 1.3 安全性能（井下否决项，地面也建议做）

按 **MT/T 1019**、试验方法 **MT 113**。玻璃钢和 UHMWPE 外层都要过，不能只测外层。

| 项目 | 指标 |
| --- | --- |
| 表面电阻 | **≤1×10⁸ Ω**（500 V，23 ℃ / 50% RH，状态调节 ≥24 h） |
| 阻燃（酒精喷灯） | 续燃 **≤5 s**，阴燃 **≤5 s**，损毁长度 **≤250 mm**；滴落物不得引燃下方 300 mm 脱脂棉 |

地面皮带廊可以放宽阻燃，但抗静电仍建议做，少积尘。井下两项同时不合格就不得入井。

## 2. 尺寸公差（玻璃钢能做的精度，不要套钢管 H8）

玻璃钢回弹、刀具磨损比钢大，**Φ175 不标 H8**。

| 尺寸 | 标注 |
| --- | --- |
| 外径 | **Φ184 0/−0.30**（车或定径后） |
| 全长 | **730 0/−1.0** |
| 两端止口孔径 | **Φ175H9**（175 **+0.100/0**），两端孔径差 **≤0.05** |
| 止口深度 | **62 ±0.20**，两端深度差 **≤0.25** |
| 止口处壁厚 | **4.5 ±0.25**，同截面壁厚差 **≤0.25** |
| 台阶径向宽度 | **≥3.0**（中间内径 **≤169**，补到图上） |
| 孔口 | **2×15°** |
| 台阶根部 | **R0.8～R1.5**（玻璃钢忌尖角，不要 0.5×45 钢件倒角） |
| 两端外倒角 | **1×45°**，倒角后纤维须用树脂封闭 |

轴承座外圆按 Φ175H9 配 **微过盈 0.05～0.15 + 结构胶**（或机械卡）。不要按钢座 n6 硬压，4.5 mm 玻璃钢壁会裂或失圆。

## 5. 图纸技术要求（替换原先钢衬条文）

1. 未注线性 GB/T 1804-m，未注形位 GB/T 1184-K。
2. 材质为玻璃钢，纤维缠绕。力学性能按本文件第 1 条。井下按 MT 113 / MT/T 1019 阻燃抗静电。
3. 两端止口宜与管体一次成型后精铰；必须机加时，止口区预留环向加厚，加工后剩余环向层 **≥2.5 mm**。
4. 台阶径向宽 **≥3.0 mm**，根部 R≥0.8。尖角机加的薄台阶，20 kN 会分层，不是压塑性。
5. Φ175H9 一次装夹或配铰。座用胶接+微过盈，压装后圆度按第 1.2 条。
6. 外圆与 UHMWPE 不得相对转动。切割面、孔口封脂，禁止纤维吸水。
7. 本件按第 1、2、3 条检验。成辊跳动 1.2 mm、阻力 3.5 N、轴向 20 kN 仍按 MT 821。

---

## 6. 检验（内衬出厂）

**逐根：** Φ184、Φ175H9、深 62、长 730、外圆跳动、外观、巴氏（两端+中点，均 ≥40）。  
**每批（至少 2 根）：** 环刚度、环向拉伸、层间剪切、两端孔同轴、径向 2500 N 抗压。  
**型式 / 换树脂配方：** 第 1.1 全项 + 第 1.2 轴向 20 kN、蠕变 72 h、跌落 + 第 1.3 阻燃抗静电。

---

## 7. 和钢衬的差别（本图不要再写）

不要写 Q235、GB/T 13793、纵缝修磨、H8、磷化防锈、n6/p6 钢过盈。玻璃钢的命门是 **环向模量、层间剪切、蠕变、阻燃抗静电**，不是屈服强度。
