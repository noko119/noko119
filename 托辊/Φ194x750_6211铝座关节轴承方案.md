# Φ194×750 方案核对：UHMWPE 5 mm + 玻璃钢衬 + 铝座 + 6211 + 关节轴承 + 轴 Φ35

对标对象：同外形 **D194 × L750、轴承 6407**（35×100×25，轴已是 Φ35）。

## 1. 结构（按你说的排）

成辊外径 **Φ194**，管体长 **750**。  
最外层 **UHMWPE，厚 5 mm** → 玻璃钢衬外径 **Φ184**。  
衬两端内口（名义 Φ175×深 62）装 **铝制轴承座**。  
座内：**6211**（55×100×21）→ **GE35** 关节轴承（35×55×20/25）→ 轴 **Φ35**。

尺寸链是通的：6211 内径 55 = GE35 外径 55，GE 内径 35 = 轴径。两端各走同一径向力，不是两套轴承分流。

## 2. 能不能用（对标 6407）

**外形、轴头、上架：能对上。** 轴 Φ35、辊 Φ194×750，和 6407 托辊同一档槽口。

**额定径向寿命：不能按 6407 等价用。** 每端径向力要同时穿过 6211 和 GE，疲劳寿命由会转的那套决定，就是 6211。

| | 6407 对标辊 | 本方案 |
| --- | --- | --- |
| 旋转轴承 | 6407，Cr≈**55 kN** | 6211，Cr≈**43.2 kN** |
| 轴 | Φ35 | Φ35（经 GE） |
| 2.0 m/s、20 000 h、两端均载 | 单辊径向约 **18 kN** | 单辊径向约 **14 kN**（约 6407 的 **78%**） |
| 4.0 m/s、20 000 h | 约 **14 kN** | 约 **11 kN** |
| 轴向拉脱 MT 821（按辊径 Φ194） | 20 kN | 仍 **20 kN** |
| GB/T 10595（按轴径 35） | 15 kN | **15 kN** |

**能用的前提（缺一条就不要对标 6407 出厂）：**

1. **关节轴承只摆角、不许转。** GE35ES 钢对钢额定是摆动，C=80 kN / C0=400 kN 不能按 197 r/min 去转。一跟着转，几天磨穿，阻力远超 3.5 N。6211 内圈与 GE 外圈必须周向锁死；轴与 GE 内圈锁死；球面只留下 ±6° 的慢摆。
2. 寿命、带面载荷按 **6211 反算（约 11～14 kN）** 标，不要印 6407 的 14～18 kN。
3. 止口深 62：6211 宽 21 + GE 外圈宽 20 + 迷宫，很紧。必须先排密封再定座长，排不下就加长止口，不许把迷宫砍没。
4. 铝座在玻璃钢里不能只靠过盈：热胀差大约 0.1 mm 量级，要 **胶 + 台阶 + 轴向挡**。铝座壁要撑住 6211 外圈圆度（压装后 Φ100 圆度 ≤0.02）。
5. **井下慎用铝座。** 摩擦火花、腐蚀、安标；井下改冲压钢座或阻燃聚合物座。地面腐蚀小可以用铝。
6. 玻璃钢衬跨中挠度 **≤0.50 mm**，中间壁台阶径向宽 ≥3 mm（或轴向模量 ≥12 GPa），否则 6211 偏斜过大。

只想要轴 Φ35、不想要调心：直接 **6407**，少一套 GE，寿命更高、阻力更稳。上 6211+GE 只为了 **轴 35 + 补偿安装偏斜**。

## 3. 玻璃钢内衬 — 材质技术要求

纤维缠绕热固 GFRP，无碱玻纤 + 间苯或不饱和聚酯或乙烯基酯。禁止短切毡单独承力。

**试样**

| 项目 | 指标 |
| --- | --- |
| 密度 | 1.70～1.95 g/cm³ |
| 结构层玻纤质量含量 | ≥55% |
| 固化度 | ≥90% |
| 巴柯尔硬度 | ≥40 |
| 孔隙率 | ≤3% |
| 环向拉伸强度 / 模量 | ≥180 MPa / **≥20 GPa** |
| 轴向拉伸强度 / 模量 | ≥80 MPa / **≥12 GPa**（挠度要过 0.50 mm，轴向模量从原 8 GPa 提高到 12） |
| 轴向压缩强度 | ≥120 MPa |
| 弯曲强度 / 模量 | ≥150 MPa / ≥12 GPa |
| 层间剪切 | ≥15 MPa |
| 冲击韧性 | ≥80 kJ/m² |
| 环刚度 SN | ≥20 kN/m² |
| 吸水 24 h | ≤0.5%；浸水后环向强度保留 ≥85% |
| 80 ℃ 弯曲保留 | ≥70% |
| 井下表面电阻 | ≤1×10⁸ Ω（MT 113） |
| 酒精喷灯 | 续燃/阴燃 ≤5 s，损毁 ≤250 mm |

环向层 ≥60%，交叉层出轴向。止口加工后剩余环向层 ≥2.5 mm。

**构件**

| 项目 | 指标 |
| --- | --- |
| 外径 / 长度 | Φ184 0/−0.30；730 0/−1.0 |
| 两端止口 | Φ175H9（+0.100/0），深 62 ±0.20（若座+密封超 62，按座图改深） |
| 台阶径向宽 | ≥3.0 mm（中间内径 ≤169） |
| 两端孔同轴 | φ0.12 |
| 跨中弯曲挠度 | ≤0.50 mm（工作径向按 6211 反算载荷） |
| 2500 N 径向抗压 | 卸载后外圆椭圆 ≤0.20 mm，Φ175 圆度 ≤0.08 mm |
| 止口轴向 | 20 kN 不分层 |
| 与 UHMWPE | 剥离 ≥50 N/25 mm，不得转套 |

外圆包 UHMWPE 前滚花或环槽。切口、孔口封脂。

## 4. 装轴承座 — 技术要求

**座：铝合金**（地面）。推荐 **6061-T6 / 6082-T6** 机加，表面 **硬质阳极氧化 ≥30 μm**。不推荐 ADC12 薄壁压铸当 6211 的外圈支承。井下不用铝，改钢座或双抗聚合物座，配合公差同一套。

**座与玻璃钢止口**

| 项目 | 要求 |
| --- | --- |
| 座外圆 | 按 Φ175H9 配，过盈 **0.05～0.15 mm** + **环氧结构胶**（如室温固化、剪切 ≥15 MPa） |
| 轴向 | 座台阶贴衬内台阶；另加挡圈或翻边压住 UHMWPE 管端。不许只靠胶抗 20 kN |
| 压装 | 导正、缓慢压入；压后衬 Φ175 圆度 ≤0.08 mm，衬外圆圆度 ≤0.25 mm，无白斑分层 |
| 防转 | 外圆滚花或轴向齿 + 胶；玻璃钢与铝的热胀差按 50 K 约 0.1 mm 计，过盈会松 |
| 根部 | 座外圆入端 2×15°；衬台阶 R0.8～1.5，禁止尖角顶裂层间 |

**座孔与 6211**

| 项目 | 要求 |
| --- | --- |
| 座孔 | **Φ100N7**（铝孔偏松时用 M7），Ra 0.8～1.6 |
| 压装 6211 | 外圈贴铝孔全宽；铝弹性模量低，座在 6211 外圈处壁厚（径向）**≥12 mm** 且有筋，压后 6211 外圈圆度 **≤0.02 mm** |
| 轴向 | 孔内挡肩 + 孔用弹性挡圈，防铝热胀后外圈爬出 |
| 游隙 | 6211 **C3**（托辊常用大游隙） |
| 润滑 | 2 号锂基脂，轴承空间 40%～60%，迷宫充满 |

**6211 与 GE35 与轴（必须锁死不转）**

| 界面 | 配合 | 锁法 |
| --- | --- | --- |
| 6211 内圈 / GE 外圈（Φ55） | 过盈（p6/H7 量级） | 端面挡圈压紧，**周向不得滑** |
| GE 内圈 / 轴 Φ35 | k6 或 m6 | 轴肩 + 挡圈；GE 内圈随轴、相对 6211 内圈只许摆 |
| GE 球面 | 只许摆动 | 选 **GE35ET-2RS / PTFE 自润滑**（免维护摆动）。钢对钢 GE35ES 要注脂，且更容易被带着转 |
| 摆角 | ≤6° | 架槽对中后实际摆角应远小于此 |

装配后手转：应只有 6211 在转，GE 外圈用记号看不得爬转。爬转即废。

**密封与长度**

迷宫非接触，内外圈不得相擦。6211（21）+ GE 外圈（20）+ 迷宫 ≥15 → 止口 **62 是下限**。画一张座内排样，不够就加深玻璃钢止口，改衬长/管长关系，不要挤密封。

**成辊考核（本方案仍按 MT 821，Φ194、L=750）**

径向跳动 ≤1.2 mm；轴向窜动 ≤1.2 mm / 500 N；旋转阻力非接触 ≤3.5 N；轴向 20 kN 座不脱；跌落、密封、寿命按该标准。阻力超了先查 GE 是否在转、铝座是否把 6211 压扁。
