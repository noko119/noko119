# 入库约定

三句话：

1. **一张图一张卡**，文件名必须等于图号。
2. **笔记进 Git，CAD 不进 Git**。卡片里写 `cad路径`，PDF 预览可放附件夹。
3. **状态不清的图不准当现行图用**（`现行` / `修订中` / `作废` 三选一）。

## 图别（机械定，工艺核对）

| 图别 | 谁主责 | 说明 |
|------|--------|------|
| 总图 | 机械 | 整机布置、带宽、头尾中心距 |
| 部件图 | 机械 | 驱动、滚筒组、托辊组、机架段 |
| 零件图 | 机械 | 轴、筒皮、支架、轴承座 |
| 工艺附图 | 工艺 | 下料展开、焊接顺序、机加基准 |
| 工装图 | 工艺 | 胎具、钻模、组对工装 |

## 必填属性

卡片 YAML 这些字段不能空：

`图号` `名称` `图别` `系列` `部件` `状态` `版本`

选填但尽量填：`带宽` `辊径` `轴承` `内径` `cad路径` `pdf`

## 文件名

```
30-图纸卡片/100C414M.md
80-附件/100C414M/100C414M.pdf
```

不要用「新图纸 2」「托辊最终版」这种名字。

## 检索

Obsidian 左上搜索直接搜图号。  
若安装 Dataview 插件，查询语句见 [[99-计算机/检索语句]]。
