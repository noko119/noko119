# 入库约定

口诀：

1. **一张图一张卡**，文件名必须等于图号。
2. **笔记进 Git，CAD 不进 Git**。卡片里写 `cad路径`，PDF 预览可放附件夹。
3. **状态不清的图不准当现行图用**（`现行` / `修订中` / `作废` 三选一）。
4. **工程图标注 ≠ PIDM**。标题栏进卡片，用验收勾选；不要用 `ui-prototype/`，不要写 SW API。见 [[99-计算机/工程图标注]]。

## 图别（机械定，工艺核对）

| 图别 | 谁主责 | 说明 |
|------|--------|------|
| 总图 | 机械 | 整机布置、带宽、头尾中心距 |
| 部件图 | 机械 | 驱动、滚筒组、托辊组、机架段 |
| 零件图 | 机械 | 轴、筒皮、支架、轴承座 |
| 工艺附图 | 工艺 | 下料展开、焊接顺序、机加基准 |
| 工装图 | 工艺 | 胎具、钻模、组对工装 |

## 必填属性

卡片 YAML 这些字段不能空（前六项必须与工程图标题栏**逐字相同**）：

`图号` `名称` `图别` `材料` `版本` `状态`

检索还不能空：`系列` `部件`

选填但尽量填：`带宽` `辊径` `轴承` `内径` `cad路径` `pdf`

零件 `材料` 写牌号（如 `Q235B`、`45`）；部件图/总图可写 `见明细`。工艺路线卡上的 `材质` 必须与 `材料` 同牌号。

## 文件名

```
30-图纸卡片/100C414M.md
80-附件/100C414M/100C414M.pdf
```

不要用「新图纸 2」「托辊最终版」这种名字。

## 标注怎么进库（不写代码）

1. 点 [[90-模板/图纸卡片]] → 存 `30-图纸卡片/图号.md`
2. YAML 填六字段 + `系列` `部件`；`cad路径` 写厂内 `.slddrw`
3. PDF 放 `80-附件/图号/图号.pdf`
4. 卡片「标注验收」三人勾选；全勾才能把 `状态` 改成 `现行`
5. **不要** `git add *.slddrw`

需要单独留痕：点 [[90-模板/工程图标注验收]] → `99-计算机/验收/图号.md`
