# 厂家公开参数表

各厂官网挂的带宽、滚筒直径、托辊直径、电机功率范围。例：铠源 DTⅡA 参数表（链接会变，以当时官网为准）。

- 谁用：机械对规格范围；采购对询价档
- 能干什么：B500～2400、辊径 Φ89～219 这类范围
- 不能干什么：当图号、当零件图、当工艺余量
- 用法：报价前可引用「公开样本范围」；出图仍回 [[DTIIA-手册-2013]] / [[DTIIA-图册]]
