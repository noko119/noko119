## 数据库（Dataview）

不装插件：打开 [[资料库.csv]]，或本夹搜索 `#资料`。

```dataview
TABLE 代号, 名称, 类别, 公开, 用法, 出图, 计算, 状态
FROM "50-资料库"
WHERE type = "资料"
SORT 用法 ASC, 代号 ASC
```

只看网上可引用：

```dataview
TABLE 代号, 名称, 链接
FROM "50-资料库"
WHERE type = "资料" AND 用法 = "网上可引用"
```

厂内该买还没备的：在对应卡片把 `状态` 改成 `修订中`，并写厂内盘路径。
