# 三位身份 · 驻库分工

本库按厂家三人会审来建，不是设计院资料室。

## 机械工程师

- 图纸按 **总装 → 部件 → 零件** 挂树，不按项目名堆文件夹
- 图号能拆才入库：系列、带宽、部件码、型式、版本
- 托辊图号拆法与报价 Skill 一致：带宽码 + 辊径档 + 型式 + 后缀
- 轴径 `D/d` 与常规辊径档冲突时，**以轴径定轴承**

入口：[[10-机械/索引]] · [[10-机械/图号规则]]

## 工艺工程师

- 先问：这张图下车间还缺什么（料、焊、加工基准、探伤、试车）
- 设计图、工艺附图、工装图分开放，禁止混在一张卡里当「最终图」
- 每张现行零件图至少能写出一条工艺路线
- 会签只写可执行意见

入口：[[20-工艺/索引]] · [[20-工艺/工艺总则]]

## 计算机工程师

- 打开方式：Obsidian → Open folder as vault → 选 `图纸库`
- 新图只用模板，不手搓 YAML
- 附件目录 `80-附件/图号/`；源文件路径写在卡片，不把 `.sldprt/.dwg` 推进 Git
- 改分类先改模板和首页，再改卡片

入口：[[99-计算机/索引]]
