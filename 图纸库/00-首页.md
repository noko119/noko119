# 皮带机厂家图纸库

用 **Obsidian 打开本文件夹 `图纸库`**，不要打开整个 Git 仓库根目录。

三位驻库身份：

| 身份 | 管什么 | 入口 |
|------|--------|------|
| 机械工程师 | 产品树、图号、总装/部件/零件 | [[10-机械/索引]] |
| 工艺工程师 | 工艺路线、工装、会签、能不能下车间 | [[20-工艺/索引]] |
| 计算机工程师 | 卡片模板、附件路径、检索、Git 约定 | [[99-计算机/索引]] |

## 日常三步

1. 新图：复制 [[90-模板/图纸卡片]] → 存到 `30-图纸卡片/`，**文件名 = 图号**
2. 附件：PDF 预览放 `80-附件/图号/`；CAD / 工程图源文件路径写在 `cad路径`（**`.slddrw` 不进 Git**）
3. 标注验收：YAML 六字段与标题栏逐字相同；卡片上三人勾选。约定见 [[99-计算机/工程图标注]]。SW 插件会审：[[99-计算机/验收/SW工程图插件-三工程师会审]]

PIDM（`ui-prototype/`）和原料采购页都不是工程图标注工具。
