# 产品系列

| 系列 | 何时用 | 图纸注意 |
|------|--------|----------|
| DTⅡ | 老线改造、互换件 | 图号可能带 `DTⅡ` 前缀 |
| DTⅡA | 现行主力 | 托辊、滚筒、中间架优先对 A 型样本 |
| DTIIDX / 加强型 | 支架加强、大运量 | 支架图无轴承字段 |
| 非标 | 业主指定、改造接口 | 必须在卡片 `系列` 写「非标」，并链总图 |

带宽常用：650 / 800 / 1000 / 1200 / 1400 / 1600 / 1800 / 2000。  
带宽未定时，卡片 `状态` 不得标现行。
