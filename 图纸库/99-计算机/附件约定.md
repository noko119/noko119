# 附件约定

| 类型 | 放哪 | 进 Git？ |
|------|------|----------|
| 图纸卡片 `.md` | `30-图纸卡片/图号.md` | 是 |
| PDF / PNG 预览 | `80-附件/图号/` | 可以，控制单文件 < 20 MB |
| DWG / SLDPRT / SLDASM / STEP | 厂内盘或 PDM | **否**，只把路径写入 `cad路径` |
| 工艺卡扫描件 | `80-附件/图号/工艺/` | 可以 |

`cad路径` 示例：

```
\\nas\图纸\DTⅡA\托辊\100C414M.SLDPRT
```

或本机：

```
D:\图纸\DTⅡA\托辊\100C414M.SLDPRT
```
