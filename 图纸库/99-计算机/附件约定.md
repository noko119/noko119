# 附件约定

| 类型 | 放哪 | 进 Git？ |
|------|------|----------|
| 图纸卡片 `.md` | `30-图纸卡片/图号.md` | 是 |
| PDF / PNG 预览 | `80-附件/图号/` | 可以，控制单文件 < 20 MB |
| DWG / SLDPRT / SLDASM / **SLDDRW** / STEP | 厂内盘或 PDM | **否**，只把路径写入 `cad路径` |
| 工艺卡扫描件 | `80-附件/图号/工艺/` | 可以 |
| 标注验收留痕 | `99-计算机/验收/图号.md` | 是（可选；日常勾选写在卡片上） |

`cad路径` 示例（工程图写 `.SLDDRW`，零件写 `.SLDPRT`）：

```
\\nas\图纸\DTⅡA\托辊\100C414M.SLDDRW
```

或本机：

```
D:\图纸\DTⅡA\托辊\100C414M.SLDDRW
```

**不要**把 `.slddrw` 拷进 `80-附件/`，也不要 `git add`。预览只用 PDF。
