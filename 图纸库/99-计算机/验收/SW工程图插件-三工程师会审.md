# SW 工程图插件 · 三工程师会审

**对象：** 用户说的「这个 SW 工程图插件」  
**仓库里实际有的：** `ui-prototype/`（PIDM 路径分类网页），**没有** `.slddrw` 插件源码。  
**本工具：** 不写代码。对着工程图勾 [[90-模板/工程图标注验收]]，约定见 [[工程图标注]]。

## 机械

1. PIDM 五面板 **不能** 当工程图标注插件。它只管 DTⅡ 十二大项路径分类，不碰图框、标题栏、明细表、尺寸。
2. 标注必须按 **总图 / 部件图 / 零件图** 分开，明细序号跟部件树走，不跟 PIDM 段名走。
3. 三张样图才能开测插件：托辊 [[30-图纸卡片/100C414M]]、支架 [[30-图纸卡片/DTⅡ04C0122]]、滚筒部件图（**图号不能唯一确定**，库内无滚筒卡）。`cad路径` 现为空，无 `.slddrw` 可打开。
4. 轴径与辊径档冲突时 **轴径优先**。采购页示例尺寸不是图纸，不准写入标题栏。

开工写插件前机械必须交齐：三张可打开的工程图、厂内图框属性冻结、滚筒明细件号顺序书面定死。PIDM 与标注 **分工程**。

---

## 工艺

1. PIDM 对下料班、焊工、车工 **没用**。`原料采购/` 只能给采购估料，余量没落到工程图上。
2. 图上必须有：成品尺寸 **和** 下料尺寸（余量是数字）、焊缝符号（坡口/焊脚/探伤，不准写「按国标」）、轴基准与形位、材质牌号、热处理、试转。托辊缺压装胎 → **缺工装不能投**（那是投产，不是插件会签）。
3. 现有示例卡标「现行 / 同意」按总则第 1 条 **不成立**：无 `.slddrw`、无 `-XL` 下料附图、无 `-GZ` 工装图。
4. 插件最低能力：标注写进 SLDDRW（导出 PDF 还在）。只改网页、不改工程图 = 不合格。

---

## 计算机

1. PIDM 和工程图标注 **不是同一套**。有人指着五面板说「这个工程图插件」时，先否定，再打开本库验收表。
2. 不写 SW API、不写宏。标注工具 = 本库模板勾选 + 标题栏六字段进 YAML。
3. 六字段必须与标题栏逐字相同：`图号` `名称` `图别` `材料` `版本` `状态`。
4. **`.slddrw` 不进 Git。** 路径写 `cad路径`，预览只用 PDF。

---

## 怎么用这个标注工具（对着 SW 点）

1. Obsidian 打开 `图纸库`（不要打开仓库根目录）
2. 在 SW 打开一张托辊、一张滚筒、一张机架 **工程图**
3. 复制 [[90-模板/工程图标注验收]] → `99-计算机/验收/图号.md`
4. 机械、工艺、计算机按表勾；任一项勾不上 = 插件不合格
5. 全勾才能把卡片 `状态` 改为 `现行`
