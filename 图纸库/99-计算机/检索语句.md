# 检索语句

不装插件：左上搜索图号，或点标签 `#托辊` `#现行`。

若安装 [Dataview](https://github.com/blacksmithgu/obsidian-dataview)，可在任意笔记粘贴：

```dataview
TABLE 图号, 名称, 部件, 图别, 状态, 轴承
FROM "30-图纸卡片"
SORT 图号 ASC
```

只看现行托辊：

```dataview
TABLE 图号, 名称, 带宽, 辊径, 轴承, 内径
FROM "30-图纸卡片"
WHERE 部件 = "托辊" AND 状态 = "现行"
SORT 图号 ASC
```
