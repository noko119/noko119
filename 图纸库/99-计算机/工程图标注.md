# 工程图标注 · 进库与验收

## 结论（先看这一条）

**PIDM 原型和工程图标注不是同一套插件。**

| 东西 | 在哪 | 干什么 | 进图纸库？ |
|------|------|--------|-----------|
| PIDM 五面板网页 | 仓库 `ui-prototype/` | 路径分类、点序、张力计算（网页原型，不连 SW） | **否**。算功率用的段类，不是图号 |
| 工程图标注 | 本库模板勾选 | 标题栏六字段进卡片 | **是**。一张图一张卡 |
| 原料采购页 | 仓库 `原料采购/` | 网页 BOM，钢管圆钢钢板 | **否**。不是工程图 |

仓库里 **没有** SolidWorks API、没有 `.slddrw` 插件代码。有人说「这个 SW 工程图插件」时：先打开本页，用验收表对照标题栏，**不要去点 PIDM，不要改网页原型**。

## 标注工具做成什么样（不写代码也能用）

点模板，勾选，填六字段。不上 SW API，不写宏，不装厂外插件。

| 步骤 | 点哪个 | 做什么 |
|------|--------|--------|
| 1 | [[90-模板/图纸卡片]] | 新图复制到 `30-图纸卡片/`，**文件名 = 图号** |
| 2 | 卡片 YAML | 填六字段（见下表），再填 `系列` `部件` |
| 3 | 卡片正文「标注验收」 | 机械 / 工艺 / 计算机各勾一项 |
| 4 | 需要单独留痕时 | 再插 [[90-模板/工程图标注验收]]，存 `99-计算机/验收/图号.md` |
| 5 | 附件 | PDF 预览 → `80-附件/图号/图号.pdf`；`.slddrw` 只写 `cad路径` |

工装图点 [[90-模板/工装图]]；总图点 [[90-模板/项目总图]]。同样填六字段、同样勾验收。

工艺路线卡 [[90-模板/工艺路线]] 的 `材质` 必须与卡片 `材料` **牌号一致**（一个写标题栏，一个写下料）。

## 工程图属性 ↔ 卡片 YAML（必须逐字相同）

标题栏 / 自定义属性 只认这六项，名称不许改、不许中英混用：

| 工程图标题栏 | 卡片 YAML | 谁填 | 空了怎么办 |
|--------------|-----------|------|-----------|
| 图号 | `图号` | 机械 | 不准入库 |
| 名称 | `名称` | 机械 | 不准入库 |
| 图别 | `图别` | 机械定，工艺核 | 只准：总图 / 部件图 / 零件图 / 工艺附图 / 工装图 |
| 材料 | `材料` | 工艺核（零件写牌号；部件/总图可写 `见明细`） | 不准标 `现行` |
| 版本 | `版本` | 机械 | 与改图单一致 |
| 状态 | `状态` | 三人会签后计算机改 | 只准：`修订中` / `现行` / `作废` |

检索还要有（可与标题栏重复，但不代替上表）：`系列` `部件`。零件尽量再填 `带宽` `辊径` `轴承` `内径`。

`cad路径` 写厂内盘上的 `.slddrw`（或零件 `.sldprt`），**路径进卡，源文件不进 Git**。

## 验收：怎么证明没标错

三对照，缺一不可：**卡片 YAML、PDF 预览、图号规则**。不要凭模型树名称、不要凭 PIDM「写入属性」、不要凭采购页材质下拉。

复制下面做：

```
0. 打开库：Obsidian → Open folder as vault → 选「图纸库」
1. 点模板「图纸卡片」（或本卡已建则跳过）
2. 填 YAML：图号、名称、图别、材料、版本、状态
3. 填检索：系列、部件
4. 文件另存为 30-图纸卡片/<图号>.md（文件名必须等于图号）
5. 把工程图导出 PDF，放到 80-附件/<图号>/<图号>.pdf
6. cad路径 写成厂内盘 …/<图号>.SLDDRW（不要 git add 这个文件）
```

三人当场勾（写在卡片「标注验收」，或验收表）：

```
机械（对照 10-机械/图号规则 + 标题栏）：
  [ ] 图号能拆（带宽码 / 辊径档 / 型式 / 后缀，或手册段码）
  [ ] 图号 = 卡片文件名 = YAML「图号」= PDF 文件名（无空格、无「最终版」）
  [ ] 名称、图别与标题栏逐字相同；图别落在五选一

工艺（对照 PDF 预览 + 工艺路线）：
  [ ] 材料与标题栏逐字相同；能下料（或部件/总图为「见明细」且明细有牌号）
  [ ] 版本与工艺卡 / 改图单同号
  [ ] 未三勾不得把状态改成「现行」

计算机（对照卡片 + 附件夹 + Git）：
  [ ] 六字段与 PDF 标题栏逐字相同，无空项
  [ ] 80-附件/<图号>/ 里有 PDF，没有 .slddrw
  [ ] git status 看不到 *.slddrw *.SLDDRW；cad路径 已填
```

全勾 → 计算机把 `状态` 改为 `现行`。有一条不勾 → 保持 `修订中`，在卡片「工艺 / 缺什么」写哪一项标错。

**判定「插件标错」的典型差：** 图号与文件名不一致；图别写成装配/零件英文；材料写成采购页规格而不是牌号；版本停在旧次；把 PIDM 段名（如 `03_承载分支倾斜段`）写进了 `名称`。

## 禁止

```
不要把 .slddrw / .SLDDRW 推进 Git
不要把 .sldprt .sldasm .dwg .dxf .step 推进 Git
不要用 PIDM 五面板当工程图标注工具
不要用原料采购页当工程图材料来源
不要为「标注」去写 SW API / 宏 / 网页插件
```

可提交：Markdown 卡片、本约定、模板、小体积 PDF（单文件 < 20 MB）。忽略规则已在仓库根目录 `.gitignore`。
