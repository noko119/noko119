## 对着 SW 工程图再勾（插件验收）

无 `.slddrw` 打开时，下列全部视为未勾。PIDM 网页勾上也不算。

### 机械（尺寸 / 明细 / 视图）

- [ ] 标题栏图号、名称、图别与卡片 YAML 逐字相同
- [ ] 零件图：辊径、轴径、轴长、辊面长（有摩擦盘则盘径）已标
- [ ] 部件图：明细序号与 BOM 一致（滚筒：筒皮、轴、辐板…；支架无轴承栏）
- [ ] 总图：带宽 B、头尾中心距、驱动位置、拉紧型式读得出
- [ ] 轴径与辊径档冲突时，图上按轴径，并有备注

### 工艺（没有这些不能投产）

- [ ] 成品尺寸和下料尺寸都在图上，余量是数字
- [ ] 材质牌号实写（Q235B / 45# 等），或部件图「见明细」且明细有牌号
- [ ] 焊缝有坡口、焊脚、探伤等级（不是「按国标」）
- [ ] 轴有基准和形位；轴承档公差对得上内径
- [ ] 试转 / 盘车 / 静平衡（滚筒）写在图上
- [ ] 工艺附图 `图号-XL`、工装图 `图号-GZ` 分图，不和零件图混在一张 SLDDRW
- [ ] 机架孔边该写「现场配作」的已写出
