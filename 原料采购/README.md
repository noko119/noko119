# 滚筒 / 托辊原料采购清单

订单来了之后，采购用的交互网页：先录滚筒、托辊台份，再对每个部件**手选或手填**钢管、圆钢、钢板、标准件，最后汇总整批下料量。

不连服务器，数据只存在本机浏览器。

本页是网页 BOM，**不是工程图**，不能当标题栏「材料」来源。工程图标注进图纸库，见 `图纸库/99-计算机/工程图标注.md`。

## 打开

```bash
cd 原料采购
chmod +x start.sh
./start.sh          # 默认 8082
```

浏览器：`http://127.0.0.1:8082/`

也可直接打开 `index.html`。

## 用法

1. 顶部改 **工艺参数**（轴端余量、轴径余量、管锯缝、筒体加工、板割缝、板材损耗%、定尺长度）。默认按大厂常用值，全部可改。
2. **订单列表** 点「+ 滚筒 / + 托辊」，填数量。可用「载入示例订单」看一遍算法。
3. 点某一行「手选部件」：填成品尺寸 →「按成品尺寸预填部件规格」→ **再勾选/改规格/改材质/删行/加行**。未勾选的不进采购清单。
4. 下方自动汇总：钢管总长与重量、圆钢重量、钢板面积与重量、标准件与外购件。
5. 复制、导出 CSV、打印。

## 规格口径

- 界面默认 **mm / kg**
- 钢管：GB 外径×壁厚，以及 ASTM NPS（4"～24" SCH40/80），也可手填任意外径壁厚
- 圆钢：GB Φ20～250，英制英寸换算 mm，可手填
- 钢板：常用厚度 + 手填；圆板可填外径/内孔，或直接填下料长×宽
- 材质：Q235B / Q355B / 45# / 42CrMo / A36 / 4140 等，可手选

## 重量

- 钢管：π(D − t)tLρ
- 圆钢：πd²Lρ/4
- 钢板：长×宽×厚×ρ；圆板净重按圆环，采购重再加损耗%
- ρ 默认 7.85 g/cm³，可改
