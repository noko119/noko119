# DTII(A) 托辊选型计算工具

**只做托辊**（不含驱动/改向滚筒）。依据《DTII(A)型固定式带式输送机设计手册》与 GB/T 10595，改参数即时重算。

## 输出（手册标准）

- 建议标准直径 `D`（仅标准档）
- 计算最小直径 `D_min`（选型依据，非产品规格）
- 标准壁厚 `δ`、辊长 `L`、轴径 `d`、轴长 `Ls`
- 标准轴承、图号、运量判断、力学校核

## 本地打开

```bash
cd dtii-roller-calc
./start.sh
# 浏览器打开 http://127.0.0.1:8081/
```

或直接打开 `index.html`。
