# DTII(A) / 全系列带速托辊与轴承计算选型系统

可在浏览器本地打开的动态计算页：改带宽、带速、能力等参数会即时重算受力、轴承、寿命与图号。

## 本地打开

直接双击：

```bash
dtii-roller-calc/index.html
```

或启动本地服务：

```bash
cd dtii-roller-calc
./start.sh
```

浏览器访问：`http://127.0.0.1:8081/`

## 说明

- 单文件页面，打开即可计算，无需联网
- 含 DTII(A) / GB 带速与 ISO·CEMA 扩展带速
- 支持手册推荐自动反算或手动指定轴承
