# 托辊图号 → 含义 + 轴承规格

用户给出**图号**和/或**名称**（可附带尺寸如 `Φ159×1000×1034`）时，输出：

1. 图号含义
2. 轴承型号
3. 内径

不要展开无关讲解，除非用户追问原因。

## 输入

接受例如：

- `180C661M 摩擦下调心托辊`
- `100C414H Φ108×380×414`
- 仅图号，或图号+名称+尺寸

缺尺寸时仍可按图号档位推断；尺寸与图号冲突时以**辊径 Φ**为准，并简短说明。

## 输出格式（固定）

每条先写图号/名称一行，再跟表：

| 项目 | 内容 |
|------|------|
| 图号含义 | 拆解各段含义 + 一句话总述 |
| 轴承型号 | 如 `6205/C4` |
| 内径 | 如 `25 mm` |

若有尺寸 `ΦD×L×A`，在图号含义中顺带注明：D=辊径，L=辊面长，A=轴长（常见）。

多条时逐条输出。

## 图号拆解规则

常见 DTⅡ / 厂家图号形如：`{带宽码}C{辊径档}{型式码…}{后缀}`

| 片段 | 含义 | 示例 |
|------|------|------|
| 前缀数字 | 带宽 B = 数字 × 10 mm | `100`→B1000，`180`→B1800 |
| `C` | 托辊类图号标记 | — |
| `C` 后第一位 | 辊径档（决定轴承） | 见下表 |
| 中间数字（如 `14` / `61`） | 结构/位置型式码 | 见“型式码” |
| 后缀字母 | 特殊型式 | 见“后缀” |

### 辊径档 → 轴承 → 内径

| 辊径档 | 辊径 Φ | 轴承型号 | 内径 d |
|--------|--------|---------|--------|
| 1 | 63.5 | 6203/C4 | 17 mm |
| 2 | 76 | 6204/C4 | 20 mm |
| 3 | 89 | 6204/C4 | 20 mm |
| **4** | **108** | **6205/C4** | **25 mm** |
| **5** | **133** | **6305/C4** | **25 mm** |
| **6** | **159** | **6306/C4** | **30 mm** |

优先用尺寸中的 Φ；无尺寸时用辊径档。

### 型式码（常见）

结合名称与常见样本：

| 片段 | 常见含义 |
|------|---------|
| `…414` / `…514` / `…614` | 上托辊侧、槽形相关（常对应约 35° 槽角体系中的“4”） |
| `…460` / `…560` / `…660` | **平形下托辊**（回程平行托辊；辊面长接近带宽，如 B1000→约 1150） |
| `…461` / `…561` / `…661` | 下调心（回程侧调心） |
| `…414` 无后缀 | 多为 **槽形托辊（常 35°）** 图号 |
| 名称写“摩擦上/下调心” | 以名称为准，覆盖纯数字猜测 |

无法从数字唯一断定时：结合用户给的**名称**写含义；名称也没有就写“结构型式码，需对照样本”。

### 后缀

| 后缀 | 含义 | 是否改轴承档 |
|------|------|-------------|
| **H** | **缓冲托辊** | 否 |
| **M** | 摩擦调心 | 否 |
| **S** | **梳形**（如平形梳形下托辊） | 否 |
| **Z** | 锥形调心（常见） | 否 |
| 无后缀 | 普通槽形/平行等（看型式码与名称） | — |

### 尺寸串 `ΦD×L×A`

| 段 | 常见含义 |
|----|---------|
| ΦD | 辊径 |
| L | 辊面长度 |
| A | 轴长（或安装相关长度） |

## 常见例（含图号含义）

### `100C414H` Φ108×380×414

- **100**：B=1000 mm
- **C4**：Φ108 档
- **14**：槽形上托辊结构码（同系列无 H 时常为 35° 槽形托辊）
- **H**：缓冲
- 尺寸：辊径 108、辊面 380、轴长 414  
→ **带宽 1000 的 Φ108 缓冲托辊**；轴承 **6205/C4**，内径 **25 mm**

### `180C661M` Φ159×1000×1034

- **180**：B=1800 mm
- **C6**：Φ159 档
- **61**：下调心结构码
- **M**：摩擦调心  
→ **带宽 1800 的摩擦下调心托辊**；轴承 **6306/C4**，内径 **30 mm**

### `100C460S` Φ108×1150×1178

- **100**：B=1000 mm
- **C4**：Φ108 档
- **60**：平形下托辊结构码
- **S**：梳形  
→ **带宽 1000 的平形梳形下托辊**；轴承 **6205/C4**，内径 **25 mm**

## 不确定时

- 图号非上表体系、辊径非标、或厂家专用码：说明无法唯一确定，给最可能档位，建议以厂家图纸为准。
- 不要编造表外轴承。

## 行为约束

- 每次都输出 **图号含义 + 轴承型号 + 内径** 三行表。
- 带宽码不决定轴承；轴承由辊径档决定。
- 不把辊面长度误当成带宽。
