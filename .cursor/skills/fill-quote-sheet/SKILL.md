# 托辊图号 → 含义 + 轴承规格

用户给出**图号**和/或**名称**（可附带尺寸）时，输出：图号含义、轴承型号、内径。  
不要展开无关讲解，除非用户追问原因。

## 查询顺序（必须遵守）

1. **先查本地目录**  
   打开并对照 [references/local-catalog.md](references/local-catalog.md)。图号/尺寸能命中则**直接按目录输出，禁止上网**。
2. **再用本 Skill 规则推断**  
   用本文件规则表、型式码、后缀、标准答案推断。能唯一确定就输出，**仍不要上网**。
3. **本地都没有再上网**  
   仅当目录+规则仍不够时才网页搜索：  
   - 陌生厂家前缀、无法拆段  
   - 无辊径/轴径且无法推断  
   - 规则冲突需旁证，或用户要官方释义  
   关键词：`图号` + `托辊` + `轴承`/`带宽`；优先厂家样本、DTⅡ/DTⅡA 图册。
4. **网上仍不确定**  
   写清“无法唯一确定 + 最可能档位”，不编造；可请用户补辊径或轴径。

轴径标注优先：若同时有 `D25`/`d30`/`D35` 与常规辊径档，**以轴径 D/d 定内径与轴承**，并在图号含义中注明与常规档的差异。

新条目经用户确认后，可追加进 `references/local-catalog.md`（用户要求写入时再改文件）。

## 输入

接受例如：

- `100C414M Φ108×Φ201×405×439`
- `100C414H Φ108×380×414`
- `180C661M 摩擦下调心托辊`
- 仅图号，或图号+名称+尺寸

缺尺寸时仍可按图号档位推断；尺寸与图号冲突时以**辊径 Φ**为准，并简短说明。

## 输出格式（固定，照此书写）

每条先写一行图号+尺寸，再跟三行表。文风与详略以下方**标准答案**为准。

### 标准答案（必须对齐此写法）

输入：`100C414M Φ108×Φ201×405×439`

输出：

**100C414M** Φ108×Φ201×405×439

| 项目 | 内容 |
|------|------|
| 图号含义 | **100**=带宽 B1000；**C4**=Φ108 档；**14**=上托辊/槽形侧结构码；**M**=摩擦调心。尺寸：辊径 108、摩擦盘约 Φ201、辊面长 405、轴长 439 → **带宽 1000 mm 的摩擦上调心托辊（摩擦辊）** |
| 轴承型号 | 6205/C4 |
| 内径 | 25 mm |

其他图号按同一模板替换各段，不要改表格列名，不要少行。

## 图号拆解规则

常见 DTⅡ / 厂家图号形如：`{带宽码}C{辊径档}{型式码…}{后缀}`

| 片段 | 含义 | 示例 |
|------|------|------|
| 前缀数字 | 带宽 B = 数字 × 10 mm | `100`→B1000，`180`→B1800 |
| `C` | 托辊类图号标记 | — |
| `C` 后第一位 | 辊径档（决定轴承） | 见下表 |
| 中间数字（如 `14` / `60` / `61`） | 结构/位置型式码 | 见“型式码” |
| 后缀字母 | 特殊型式 | 见“后缀” |

### 辊径档 → 轴承 → 内径

| 辊径档 | 辊径 Φ | 轴承型号 | 内径 d |
|--------|--------|---------|--------|
| 1 | 63.5 | 6203/C4 | 17 mm |
| 2 | 76 | 6204/C4 | 20 mm |
| 3 | 89 | 6204/C4 | 20 mm |
| **4** | **108** | **6205/C4** | **25 mm** |
| **5** | **133** | **6305/C4** | **25 mm** |
| **6** | **159** | **6306/C4** | **30 mm** |

优先用尺寸中的辊径 Φ；无尺寸时用辊径档。

### 型式码（常见）

| 片段 | 常见含义 |
|------|---------|
| `…414` / `…514` / `…614` | 上托辊/槽形侧结构码 |
| `…414` + **M** | **摩擦上调心托辊（摩擦辊）** |
| `…414` + **H** | 缓冲托辊 |
| `…414` 无后缀 | 多为槽形托辊（常 35°） |
| `…460` / `…560` / `…660` | 平形下托辊 |
| `…460` + **S** | 平形梳形下托辊 |
| `…461` / `…561` / `…661` + **M** | 摩擦下调心托辊 |

无法从数字唯一断定时：结合用户给的**名称**写含义；名称也没有就写“结构型式码，需对照样本”。

### 后缀

| 后缀 | 含义 | 是否改轴承档 |
|------|------|-------------|
| **H** | 缓冲托辊 | 否 |
| **M** | 摩擦调心 | 否 |
| **S** | 梳形 | 否 |
| **Z** | 锥形调心（常见） | 否 |

### 尺寸串

| 形式 | 各段常见含义 |
|------|-------------|
| `ΦD×L×A` | 辊径 × 辊面长 × 轴长 |
| `ΦD×Φd×L×A` | 辊径 × **摩擦盘直径** × 辊面长 × 轴长（摩擦辊，如 `Φ108×Φ201×405×439`） |

## 其他常见例

### `100C414H` Φ108×380×414

| 项目 | 内容 |
|------|------|
| 图号含义 | **100**=带宽 B1000；**C4**=Φ108 档；**14**=上托辊/槽形侧结构码；**H**=缓冲。尺寸：辊径 108、辊面长 380、轴长 414 → **带宽 1000 mm 的 Φ108 缓冲托辊** |
| 轴承型号 | 6205/C4 |
| 内径 | 25 mm |

### `100C460S` Φ108×1150×1178

| 项目 | 内容 |
|------|------|
| 图号含义 | **100**=带宽 B1000；**C4**=Φ108 档；**60**=平形下托辊；**S**=梳形。尺寸：辊径 108、辊面长 1150、轴长 1178 → **带宽 1000 mm 的平形梳形下托辊** |
| 轴承型号 | 6205/C4 |
| 内径 | 25 mm |

### `180C661M` Φ159×1000×1034

| 项目 | 内容 |
|------|------|
| 图号含义 | **180**=带宽 B1800；**C6**=Φ159 档；**61**=下调心结构码；**M**=摩擦调心。尺寸：辊径 159、辊面长 1000、轴长 1034 → **带宽 1800 mm 的摩擦下调心托辊** |
| 轴承型号 | 6306/C4 |
| 内径 | 30 mm |

### DTⅡ / DTK 装配图号（补充）

形如 `DTII05C2133`、`DTK08C0144`：

| 片段 | 含义 |
|------|------|
| `DTII` / `DTⅡ` / `DTK` | DTⅡ / DTⅡA 类前缀（K 多为厂内变体） |
| 两位带宽序号 | `04`→B1000，`05`→B1200，`06`→B1400，`08`→B1800 |
| `C01xx` | 槽形托辊组 |
| `C07xx` / `C08xx` | 缓冲托辊组（角以名称为准，如 35°） |
| `C21xx` | 平行下托辊 |
| 末位辊径倾向 | 与 Φ 档对应：…2≈108，…3≈133，…4≈159（以尺寸为准） |

### 成套装置（无辊径时）

`GHJP1000` 等纠偏组：**JP≈纠偏**，数字=带宽；**无辊径则不能唯一定轴承**，先列常见 Φ 对应轴承，本地无样本再上网。

## 不确定时

- 先完成本地推断；仍不够再按「查询顺序」上网。
- 图号非上表体系、辊径非标、或厂家专用码：说明无法唯一确定，给最可能档位，建议以厂家图纸为准。
- 不要编造表外轴承。

## 行为约束

- 每次只输出标准三行表（图号含义 / 轴承型号 / 内径），写法对齐上方标准答案。
- **本地能答就不搜索**；搜索只为补本地缺口。
- 带宽码不决定轴承；轴承由辊径档（或显式轴径）决定。
- 不把辊面长度误当成带宽。
- 纯查询问答时不要改仓库、不要推送、不要更新 PR。
- 仅当用户明确要求把新规则写入 Skill 时才改本文件。
