# 填写报价表 · 使用说明

把本对话里的做法固化成项目内 Skill，专门用来**填报价表时查图号含义、轴承型号、内径**。

## 一句话怎么用

打开本仓库 → Agent 对话 → 输入：

```text
/fill-quote-sheet
```

然后粘贴图号（或直接粘贴图号，Agent 也会匹配本 Skill）：

```text
180C661M Φ159×Φ270×1000×1034 摩擦下调心托辊
```

得到固定三行表，可直接抄进报价表。

## 文件在哪（仅项目内，无全局）

```text
.cursor/skills/fill-quote-sheet/
├── SKILL.md                         # 规则与输出格式
├── references/local-catalog.md      # 本对话已确认的本地条目
└── 使用说明.md                       # 本文件
```

## 输出长什么样

| 项目 | 内容 |
|------|------|
| 图号含义 | 分段拆解 + 一句话总述（方便写备注/说明） |
| 轴承型号 | 如 `6205/C4` |
| 内径 | 如 `25 mm`（即轴径） |

## 查询顺序（已写进 Skill）

1. 先查 `references/local-catalog.md`
2. 再用 `SKILL.md` 规则推断
3. 本地都没有 → 才上网
4. 仍不确定 → 标明不确定，不编造

## 输入尽量带齐（报价更准）

| 信息 | 例子 | 作用 |
|------|------|------|
| 图号 | `100C414M`、`DTK08C0144` | 拆带宽/型式 |
| 名称 | 摩擦下调心托辊、35°缓冲托辊 | 定类型 |
| 尺寸 | `Φ108×380×414`、`Φ159×Φ270×1000×1034` | 定辊径/摩擦盘 |
| 带宽/系列 | `B=1000`、`DTⅡA` | 核对 |
| 轴径 | `D25`、`d30`、`D35` | **优先于**常规辊径档 |

## 本地快速对照（常用）

| Φ | 默认轴承 | 内径 |
|---|----------|------|
| 108 | 6205/C4 | 25 mm |
| 133 | 6305/C4 | 25 mm |
| 159 | 6306/C4 | 30 mm |
| 显式 D35 | 6307/C4 | 35 mm |

后缀速记：`H`缓冲 · `M`摩擦调心 · `S`梳形 · `Z`锥形调心  

图号前缀速记：`100`→B1000 · `180`→B1800 · DTⅡ 的 `04`→B1000 · `05`→B1200 · `08`→B1800  

## 本对话已沉淀的典型题

- `100C414H` / `100C414M` / `100C461M` / `100C460S`
- `180C661M` 摩擦下调心
- `DTK08C0144` 槽形、`DTK08C0744` 35°缓冲
- `DTII05C2133` 平行下托辊
- 电液犁式卸料器配套辊（注意有 `D35` 时改 6307）
- `GHJP1000/1400` 纠偏组（无辊径不能唯一定轴承）
- 托辊支架无轴承；B1000 槽形组示例图号 `DTⅡ04C0122`

完整表见：`references/local-catalog.md`

## 以后怎么维护

1. 新图号查对后，说一句「写入本地目录」→ 追加到 `local-catalog.md`
2. 合并 PR 后本机 `git pull`，报价只开本仓库即可
3. **不要**拷到 `~/.cursor/skills/`（仅报价用，避免污染其他项目）
