# 皮带机 PIDM · UI 网页原型

用于评审 SolidWorks 插件五面板交互（先以网页形式呈现）：

1. 引用分类  
2. 点序  
3. 提取检查  
4. 审核总览  
5. 发送网页  

## 本地打开

直接双击打开：

```bash
ui-prototype/index.html
```

或启动本地服务：

```bash
cd ui-prototype
python3 -m http.server 8080
```

浏览器访问：`http://localhost:8080`

## 说明

- 本原型仅展示 UI 与流程，不连接 SolidWorks，不执行真实计算。  
- 分类口径按 DTⅡ 手册十二大项 + 细分。
