操作说明

  • 3D：左键选/拖点，中键或 Alt+左键旋转，滚轮缩放；拖点改 XYZ。
  • 2D 俯视：改 X/Y；Z 用右侧表或选中后改高程。
  • 2D 侧视：改 X/Z（看坡度/高差）。
  • Easy 向导：少参数生成斜坡机 + Auto Return（对标 Sidewinder）。
  • DXF：导入 LINE/LWPOLYLINE 中心线后可 Auto Return。
  • Auto Return（默认）：只画/改承载；回程自动跟随锁定。
  • Advanced：可单独改回程；局部模板/竖曲线/D2 在此精修。
  • 颜色：蓝=承载，橙=回程，黄=闭合段。
