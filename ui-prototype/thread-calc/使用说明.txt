【这才是螺纹几何工具 · 不是皮带机 PIDM】

本压缩包里的页面标题应是：
  THREAD LAB · 螺纹尺寸推导

若你看到「皮带机区段分类与逐点张力」，说明开错了页面。

————————————————————
Windows 用法（推荐）
————————————————————
1. 解压整个文件夹
2. 双击「启动工具.bat」
3. 浏览器会打开螺纹工具页面
   正确地址类似：http://localhost:8080/

————————————————————
Mac / Linux 用法
————————————————————
1. 解压
2. 在本文件夹打开终端，执行：
   chmod +x 启动工具.sh && ./启动工具.sh
3. 浏览器打开 http://localhost:8080/

————————————————————
怎么确认开对了
————————————————————
页面上方应有大字「螺纹尺寸推导」和「THREAD LAB」
可输入 M20，会显示牙顶 / 牙底 / 退刀槽数据

不要打开上层的 ui-prototype/index.html（那是皮带机插件原型）。
