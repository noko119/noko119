【独立螺纹几何工具 · 仅 Windows】

本压缩包标题页应是：THREAD LAB · 螺纹尺寸推导
若看到「皮带机区段分类与逐点张力」，说明开错了页面。

————————————————————
Windows 用法
————————————————————
1. 解压整个文件夹
2. 双击「启动工具.bat」
3. 浏览器打开后确认标题是「螺纹尺寸推导」
   地址一般为：http://127.0.0.1:8080/

本机需已安装 Python（用于本地网页服务）。
若双击后闪退，可在本文件夹打开命令提示符执行：
  python -m http.server 8080
然后浏览器访问 http://127.0.0.1:8080/

————————————————————
怎么确认开对了
————————————————————
页面有「THREAD LAB」与「螺纹尺寸推导」
输入 M20，应显示牙顶 / 牙底 / 退刀槽数据

本工具仅提供 Windows 启动方式（见项目规则 §1.3）。
